# 可信度地面拟合前的滤波

## 目的与范围

在稀疏高程观测中减轻随机高度噪声，并检验是否改善补值，而不是仅让地图看起来平滑。
滤波独立于五种拟合后端；默认 `terrain_filter_method=none`。
用户要求在可信度开发分支加入滤波并重新比较，本次在现有隔离工作树单项开发。

## 数据如何流动

原始高程范围 -> 当前候选拟合窗口内的输入样本 -> 一次滤波 -> 选定后端拟合 ->
原始样本支持与危险检查 -> 有效地面估计 -> 各平台评价和规划。

滤波只更改拟合样本的代表高度 `z`。坐标、最高/最低高度、原始地图、缺测位置和样本数量保持可追溯。
过滤后的样本不写回原始图、不成为下一次滤波输入、不新增缺测观测。
主矩阵与常规推导使用原始高程快照。估计器依赖的是传入的不可变 ElevationRangeView；
请求级起点补丁视图中的假定高度也会被该接口返回，并可能参与滤波。当前接口没有逐点来源字段，
因此不能无条件说所有调用都只使用真实测量。本轮主矩阵不调用起点补丁；该请求场景没有进行新滤波验证。
同一个样本在不同候选窗口中可能有不同滤波结果，因为邻域只取本候选窗口中已有点；这不是全图固定预处理。
不额外扩大估计器依赖范围，增量失效范围沿用现有拟合窗口。

## 三种设置

| 设置 | 计算方式 | 主要限制 |
|---|---|---|
| none | 使用原始代表高度 | 保留原有基线行为 |
| median | 取物理邻域原始高度中值，偶数数量取中间两值平均 | 边缘少数表面可能被多数表面替换，稀疏时容易偏向一侧 |
| bilateral | 对邻域原始高度加权平均，同时降低远点和高度差大的点的权重 | 大离群点可能因与邻居差异大而被保留；斜坡上也可能抑制有效邻居 |

共同邻域为欧氏距离不超过 0.10 m，包含自身；至少 3 个输入样本才滤波，否则保持原高度。
双边滤波固定空间标准差 0.075 m、高度标准差 0.03 m：

`weight = exp(-distance^2/(2*0.075^2) - height_difference^2/(2*0.03^2))`

用原始当前点高度作高度差参考，全部权重都来自同一份未滤波输入。
参数在看到新实验结果前固定，不按测试地形或真值选择。
中值和双边滤波不是雷达传感器误差模型；不读取强度、入射角、位姿协方差或时间序列。

## 保留哪些原始检查

最终模型对原始代表高度重新判断共识，至少 4 点、70%比例与二维支撑仍需满足。
真实最高/最低范围、中心差、邻接跳变、二阶差、同向替代表面以及角度包围继续使用原始证据。
可信度的残差项也来自原始样本，因此滤波不能仅通过抹小残差就人为提高证据评分。
各平台在原始中央区域的障碍/支撑检查保持独立。

启用滤波的 grouped_ransac 还用同参数对原始样本运行分组拟合，最终共识为滤后选组、原始选组和原始残差支持的交集，交集还需重新满足原始分组的连通与严格包围要求。
原因是中值可能把异常桥点压平，先连起两个原本断开的点组；之后即使删掉该桥点，普通二维支撑检查仍可能通过。
原始分组复核同时保留连通支撑与多表面歧义判断。它增加一次原始 RANSAC 拟合，耗时必须计入；none不增加此步骤。

这会限制噪声下的补值恢复：滤波后的模型即使更准，原始证据如果仍不充分，算法也可能拒绝补值。
这是本实验的行为边界，报告必须同时给出误差、覆盖率、有用恢复率和危险诊断。
完全没有观测到的沟底无法靠滤波恢复；隐藏窄沟仍是必须保留的反例。

## 接口与验证

`TraversabilityProfile.terrain_filter_method` 沿正式构图接口传递，参与配置校验与缓存身份。
ROS 参数 `terrain_filter_method` 接受 none/median/bilateral，默认 none，非法名称拒绝启动，运行中切换拒绝。
实验探针增加最后一个可选 FILTER 参数，旧调用默认 none。

正式矩阵复用上一轮冻结输入与解析真值，以 5 后端 x 3 滤波同输入比较。
在各自接受目标上统计覆盖率与误差；另在同一后端滤波前后共同接受目标上公平比较误差。
先分析各地形/扰动/分辨率，再读总体；随机种子簇区间排除固定遮挡和重复条带。
主矩阵并行只用于正确性，性能用独立串行新进程重复测量。
本机 Jazzy 结果不代替 Humble、Orin、真实雷达或车辆验证。
