# 四种地表拟合方法：原理、实际实现与使用边界

本文说明 `dev/terrain-confidence` 在 2026-10-05 实现的四种候选方法，以及保留的基线。参数依据当前源码核对。本文是对比报告的原理附录，实验结果与使用判断见配套完整报告；算法原理不替代实车验证。

## 1. 四种方法共同要解决什么问题

假设地图上缺了一个格子的地面高度，但它周围还有一些真实测量。算法先用这些邻点猜一块地表，再读取这块地表在空格位置的高度和坡度。

最直观的区别是：平面方法像在邻点上放一块小板；MLS 像放一块可以弯曲的小薄片；RANSAC 先判断哪些点属于同一块地面，再放小板；GP 在一块小板的基础上估计平滑起伏，同时计算模型内的不确定程度。

它们使用的输入完全相同：邻点的地图平面坐标，以及该格原始高程区间的最低值、最高值和中点。拟合高度使用区间中点，原始最低值和最高值保留给障碍检查。当前接口没有雷达强度、传感器到点的距离、入射角、定位协方差等信息。因此，下面的“距离权重”指邻点离待估格子的距离，“测量质量”使用高程区间宽度作代理。

这是一个二维位置对应一个地面高度的模型。它适合表达坡面和缓慢起伏，不能完整表达悬空层、垂直壁面或同一位置的多层几何。

## 2. 基线：稳健平面 `baseline`

基线先找一块最贴近邻点的平面。它会降低偏离平面的点的影响，再用最终认可的点重新拟合。

例如，绝大多数点落在一片坡面上，只有一个点高出很多，算法会减小这个点对坡度的影响。它不会因此删除原始高点；这个高点仍参与后续障碍判断。

当前实现的步骤是：

1. 从等权最小二乘平面开始，估计中心高度和两个方向的坡度。
2. 最多做 4 次稳健重加权。偏离平面越远，影响越小；若所有点的偏离都小于 `1e-10 m`，提前停止。
3. 将竖直高程残差不超过 `0.03 m` 的点标为有效点。
4. 要求至少 4 个有效点，且占当前窗口测量点的至少 70%；用这些点做一次等权平面拟合。
5. 再经过所有共用检查，决定是否输出估计。

重加权的转折点是允许残差的一半，默认 `0.015 m`。在转折点以内，权重为 1；以外的权重按 `0.015 / 绝对残差` 下降。

它的长处是模型简单，斜坡容易解释，少量离群点不会直接支配结果。它的限制是只有一块平面：真实地表若有弯曲，就可能出现系统性高度偏差；两块不同地面被放进同一窗口时，也可能被拟合成一块折中的坡面。后者需要共同检查来拦截，不能只看平面拟合是否成功。

## 3. 加权稳健平面 `weighted_plane`

这仍然是一块小板，变化在于每个邻点的影响不同：离空格近的点影响更大；原始高程区间较窄的点影响更大；明显偏离当前平面的点继续被降权。

当前固定计算方式如下。

| 项目 | 实际实现 |
|---|---|
| 距离核 | `exp(-距离² / (2 × support²))`，默认 `support = 0.20 m` |
| 区间宽度权重 | `1 / (1 + (区间宽度 / (2 × 残差门槛))²)`，默认分母尺度 `0.06 m` |
| 稳健权重 | 与基线相同的转折公式，默认转折点 `0.015 m` |
| 重加权次数 | 固定 6 次 |
| 有效点门槛 | 最终模型的竖直高程残差不超过 `0.03 m` |
| 求解 | 坐标除以 `support` 后求解 3 个平面系数，再换回米单位 |
| 数值检查 | Cholesky 剩余对角必须大于正规矩阵最大对角的 `1e-8`；系数必须有限 |

三种权重相乘，且距离和区间宽度权重在每一轮中都保留。与基线不同，当前加权方法在 6 次重加权后直接保留该模型，没有再把有效点改成等权重新拟合。

这种设计使近处、较一致的测量更能决定待估位置的地表，有助于减少远处点或区间很宽的点的影响。但“区间窄”不等于“测得正确”：如果一组点受同一种定位偏差影响，全部落在错误的位置上，它们仍可能很一致。若当前数据每格只有一个高度，区间宽度都为零，这个质量代理就没有区分作用。

本次主对比矩阵正是单值 `float32` 输入，同坐标栅格按恒等变换写入高程图后，每格最低值等于最高值。因此区间质量权重恒为 1，MLS 使用的同一质量权重也恒为 1。主矩阵能够比较距离加权和稳健拟合的效果，但不能据此证明区间质量加权在真实多回波或多次观测数据上的收益。

它仍然只有一块平面，因此不能直接解决曲面偏差，也不能辨认完全没有观测的沟底。是否比基线更合适，要分别比较精度、补值数量、错误放行和耗时。

## 4. 局部二次 MLS `mls`

MLS 在每个待估位置附近重新拟合地表。这里采用二次曲面，让地表除了倾斜，还能向上、向下弯曲；中心高度和坡度分别从曲面及其导数读取。

PCL 官方教程将 MLS 描述为局部多项式重建，并演示了二阶拟合和法向估计。本项目实现的是适用于高程栅格的局部加权二次高度模型，没有调用 PCL，也没有照搬其全部点云处理流程。[PCL MLS 官方教程](https://pointclouds.org/documentation/tutorials/resampling.html)

当前曲面包含 6 项：常数、两个方向的一次项、两个方向的平方项，以及两个方向的乘积项。可以将它理解为“中心高度、中心坡度和弯曲程度”。

| 项目 | 实际实现 |
|---|---|
| 曲面阶数 | 二次，6 个系数 |
| 距离、区间质量、稳健权重 | 与 `weighted_plane` 相同 |
| 重加权次数 | 固定 6 次 |
| 坐标尺度 | 两个方向的坐标均除以默认 `0.20 m` 的 `support` |
| 二次拟合最低点数 | 6 个，但点数够了仍须通过数值可辨识检查 |
| 秩与病态检查 | Cholesky 剩余对角须大于最大对角的 `1e-8` |
| 退化处理 | 点数不足或二次项无法可靠求解时，回退到加权稳健平面，并记录 `used_fallback` |
| 曲率正则化 | 没有加入 ridge 惩罚；无法辨认的二次项通过回退处理 |
| 有效点门槛 | 相对最终曲面的竖直高程残差不超过 `0.03 m` |

它的表达能力比平面强，缓慢变化的凸面、凹面可以由曲面直接描述。这是模型能力，不意味着每一张稀疏地图上都会得到更好的结果。

二次项也带来了代价：需要更多、分布更合理的点；噪声可能影响弯曲程度；一片地表若实际上是台阶，曲面也可能试图把它解释成平滑过渡。因此集成代码保留原始相邻突变和二阶差检查，即使曲面拟合残差为零，也不能跳过这些检查。

MLS 回退率也需要单独统计。如果某种稀疏场景下多数位置都回退到平面，那么该场景的结果主要反映平面能力，不能全部归功于二次曲面。

## 5. 空间分组 RANSAC `grouped_ransac`

RANSAC 的思路是：先用少量点提出“这是一块怎样的平面”，再看有多少测量支持它。PCL 官方教程提供了用 RANSAC 找平面及其有效点的示例。[PCL 平面分割官方教程](https://pointclouds.org/documentation/tutorials/planar_segmentation.html)

本项目在这个思路上增加了多平面提取和空间分组。它不直接把窗口里数量最多的一片地面延伸到空格，而是寻找在空间上相连、能够从周围支持待估位置的局部平面。

当前流程是：

1. 按坐标和高程排序输入，用固定种子生成候选，保证相同输入可复现。
2. 先尝试全部剩余点的最小二乘平面。如果所有点已经满足残差门槛，直接采用这次提取结果。
3. 否则，10 个点及以下枚举所有三点组合；更多点时，每个提取轮最多进行 128 次三点采样尝试。重复抽到同一索引或几何退化的三点不形成有效候选。
4. 按有效点数选出平面；数量相同则选有效点残差平方和更小的候选。对有效点做 2 轮重新拟合和重选，再做最终平面拟合。
5. 最多提取 4 轮平面。每一轮的有效点按空间连通关系分组。
6. 每个局部组重新拟合后，向全部原始测量招募符合该平面的点，再做一次连通分组。这样可重新汇合因提取顺序而被分开的同一地面，同时保留不受支持的空间断口。
7. 局部组再做 2 轮有效点细化。只保留能够严格从周围支持待估位置的组；如果多个组在待估位置给出相差超过 `0.03 m` 的高度，返回无估计。

关键参数如下。

| 项目 | 实际实现 |
|---|---|
| 平面有效点门槛 | 竖直高程残差 `0.03 m`；不是到平面的垂直几何距离 |
| 最大提取轮数 | 4 |
| 大窗口采样尝试数 | 每轮最多 128 |
| 连通距离 | `max(2.1 × 栅格分辨率, 0.8 × support)`；5 cm 栅格和默认 support 下为 `0.16 m` |
| 局部组最低点数 | 4 |
| 最近支持点 | 与待估位置距离不超过默认 `0.20 m` |
| 环绕要求 | 相邻支持方向的最大角度缺口严格小于 `π - 1e-9` |
| 最终局部组偏好 | 累加 `1 / (1 + 距离² / support²)`，选择局部支持更强的组 |
| 最终输出 | 一块选中的局部平面及其有效点掩码；不是混合多块平面后的平均地表 |

它能够把不同平面和不连通的片段分开，这有助于减少跨越明显断口的补值。代价是需要做候选提取和分组，并且它自己的环绕检查比共用检查更严格。在点很稀疏或只从单侧观测到地面时，它可能不给出估计。

连通距离只是固定的建模尺度。如果真实沟很窄，两边的点可能仍在同一个连通组中。若沟底完全没有回波，两岸又恰好共面，RANSAC 仍可能找到一块很一致的平面。因此“做了分组”不能直接解释成“识别了所有空洞”。

## 6. 有限样本 GP `gaussian_process`

GP 把相邻位置的高度看作相关的量：近处测量对当前位置的影响通常更强。它可以同时给出预测值和预测方差。预测分布是给定测量、核函数和噪声假设之后的条件分布；GPML 第 2 章给出了对应均值和方差公式。[GPML 第 2 章，式 2.23–2.26](https://gaussianprocess.org/gpml/chapters/RW2.pdf)

本实现先用加权稳健平面估计整体倾斜，再让 GP 拟合相对这块平面的剩余起伏。直观上，是先放小板，再估计薄片应该在小板上方或下方弯曲多少。

| 项目 | 实际实现 |
|---|---|
| 均值模型 | `weighted_plane` 的完整稳健平面 |
| GP 候选测量 | 均值平面的有效点，至少 4 个 |
| 单次 GP 样本上限 | 32 |
| 选点 | 从距待估位置最近的点开始，逐次选择与已选点集合距离最远的点 |
| 核函数 | 平方指数核，也称 RBF 核 |
| 核长度 | `0.6 × support`，默认 `0.12 m` |
| 信号方差 | `max(0.0004 m², 均值平面有效点的残差均方)` |
| 观测噪声项 | `0.0001 m² + 区间宽度² / 12 + 1e-10 m²` |
| 求解 | Cholesky 分解，分别求解残差系数和方差项；每次线性求解均包含前代入和后代入，系数与预测方差必须有限 |
| 最终有效点 | 重新按相对 GP 地表的竖直高程残差 `0.03 m` 判断 |
| 输出方差 | 待估中心位置的潜在地表预测方差，数值负值截到 0 |
| 评分衰减 | 原有评分再乘 `1 / (1 + 预测标准差 / 0.02 m)` |

`0.0004 m²` 对应 2 cm 的信号标准差下限；`0.0001 m²` 对应 1 cm 的观测噪声标准差。区间宽度平方除以 12 是当前实现的噪声代理，不是实测雷达噪声标定结果。核长度和噪声基础尺度在此次实现中固定，没有逐场景用真实答案调参，也没有优化核超参数。

主矩阵使用单值高程，因此这里额外的 `区间宽度² / 12` 项也始终为 0。其结果没有检验宽区间测量对 GP 噪声项的影响，不能代替真实测量质量数据上的实验。

32 点上限控制了每个局部求解的规模，但它也意味着点很多时并未使用全部有效点做 GP 矩阵求解。最终残差检查仍遍历当前窗口的所有原始点。

这种模型可表达平面以外的平滑起伏，并用一个额外量反映模型内的预测不确定程度。它的限制包括核和噪声尺度的假设、均值平面有效点筛选，以及矩阵求解开销。某些真实曲率若先被均值平面当作离群点排除，就不会进入 GP 训练样本。

### 方差小，具体说明了什么

这里的 GP 方差回答的是：假定地表遵循当前平滑模型、均值平面已经确定、噪声尺度如上，已有测量对这个位置的高度约束有多强。

它没有把均值平面参数误差、核参数误差、定位误差、遮挡原因或地表是否存在全部算进去，也没有在潜在地表方差上再加一份未来测量噪声。因而不能把这个方差或最终评分直接换成“车辆安全概率”。这仍然是估计机制，需要用真实答案和失败场景检验其用途。

例如，两岸测量都落在同一高度，但中间是一条没有回波的深沟。模型只看到了两岸，可能认为中间也是平滑地表，甚至给出较小的模型方差。基线、加权平面、MLS 和 GP 都存在这一信息缺口；RANSAC 分组有机会阻止明显的空间断口，但断口窄于其连接尺度时也不能保证阻止。这里的判断来自模型所使用的信息，不是在本文宣告某一方法已经通过或失败了实验。

## 7. 五种方法共用的检查与评分

候选方法负责提出一块地表。集成代码另行检查它有没有足够证据、有没有抹平障碍，以及机器人是否能够通行。方法成功拟合，不等于系统一定接受补值。

### 支持范围与原始证据

在常规地表推导和本次主对比矩阵中，所有方法只读取同一份不可变的原始高程图。该推导得到的估计值不会写回原始图，也不会递归成为下一次估计的测量证据。请求级起点补丁使用独立的假定高程视图，其范围和处理方式见下一节。

默认先尝试坐标轴方向半宽约 20 cm 的方形窗口；不通过时依次缩小，再扩展到坐标轴方向半宽约 30 cm。以 5 cm 栅格为例，尝试的半宽格数依次为 `4、3、2、1、5、6`。30 cm 是方形窗口轴向半宽，不是所有邻点的欧氏距离上限；最近有效支持点仍须在 20 cm 内。窗口最多允许 32 格半宽。

共同检查包括：

- 至少 4 个有效点，且有效点占窗口原始测量的至少 70%。
- 最终有效点必须有二维分布；共线或近乎共线不能支撑地表。协方差行列式须超过 `1e-4 × (xx + yy)²`。
- 至少 3 个非中心有效点；将其方向排序后，最大角度缺口不超过 `π`，带 `1e-10` 数值容差。RANSAC 在此之前还要求严格环绕。
- 窗口内原始高程区间端点相对候选地表的最大偏离不超过 `0.10 m`；离群点的原始端点也参与这项检查。
- 若中心已有真实测量，测量中点与估计中心高度的差不能超过 `0.04 m`。
- 分辨率超过 `0.10 m` 时，不填补缺测中心；已有测量仍可估计地表。

### 突变检查

目标附近 `3 × 3` 范围内的相邻突变会否决该位置的估计。当前相邻高程差扣除中心线性坡度后，超过 `2 × 0.03 = 0.06 m` 时记录突变；原始三个连续点的二阶差超过 `0.08 m` 时也记录突变。高程区间过宽且端点相对地表超过残差门槛，也参与检查。

平面方法在所有原始端点残差都不超过 2 cm 时，可以使用已有的快速通过逻辑。MLS 和 GP 一律执行突变检查：曲面残差很小，不能证明原始二阶差很小。相邻突变扣除的是中心线性坡度，不能扣除整个曲面起伏来把台阶解释掉。

远处突变的处理与中心不同。代码优先寻找局限在当前地面上的窗口；如果远处跳变只来自被剔除的孤立点，可以保留受支持的地表。若跳变发生在拟合认可的地面中，或一致的另一组高程证据跨过待估位置，就不能当成孤立噪声丢掉。这些逻辑仍不能补出完全没有回波的真实沟底。

### 可信度评分

评分由以下因素相乘组成。

| 因素 | 当前作用 |
|---|---|
| 中心是否实测 | 实测乘 1；缺测补值乘 `0.85` |
| 一致比例 | 乘有效点数 / 全部原始点数 |
| 有效点数量 | `0.5 + 0.5 × min(有效点数 / 8, 1)`；4 点时为 0.75，8 点及以上为 1 |
| 最近支持距离 | `1 - 0.5 × 最近距离 / support` |
| 拟合残差 | 除以 `1 + 有效点 RMS / 0.02 m` |
| GP 模型方差 | GP 额外乘前述方差衰减，其他方法的该因子为 1 |

最终评分低于默认 `0.20` 时，该候选不被接受。`0.20` 是这个估计机制的接受门槛；机器人的坡度、台阶、底盘间隙和足部支持由后续平台条件另行决定。

因为 GP 多了一个衰减因子，同一个评分门槛会影响不同方法的补值数量。比较时应同时看总体覆盖率，以及各方法都接受的同一组位置上的误差。只比较各自剩下的少量成功补值，会把“拒绝更多”与“估计更准”混在一起。

## 8. 集成之后，哪些环节确实换了方法

此次可切换的是 `TerrainObservationEstimator` 中的候选地表拟合。后面的 `MeasureTerrainPatch` 仍使用共用的稳健背景平面和原始局部高低值进行平台判断。

ROS 启动配置中的背景轴向半宽默认是轮式 40 cm、足式 20 cm；它与上面的地表估计支持距离是两个不同参数。背景从相邻差分的中位数开始，再做一次稳健加权平面细化。在常规原始视图中，背景缺失的中心及其邻格可使用各自受支持的估计，但 `observed_count` 仍只统计真实测量，真实高低面的支持判断只使用这部分原始点。

当中心有有效地表估计时，背景最终使用该估计的中心梯度计算坡度。原始障碍高低差和底盘抬升仍相对共用背景计算，没有改成“减去整块曲面后只看很小的残差”。这样能保留原始障碍证据，但也意味着曲面拟合能力提升未必直接改变通行状态。

精细通行图还会检查机器人的整个包络范围，取相关位置中更差的通行状态和可信度。可信度以默认 `confidence_weight = 2.0` 进入软通行代价；它不替代坡度和障碍等硬条件。受支持的补值可能进入规划用高程，因此仍须比较错误放行和实际路径，不能只比较补值图是否更平滑。

方法通过 ROS 启动参数 `terrain_fit_method` 选择，默认保留 `baseline`，另外可选 `weighted_plane`、`mls`、`grouped_ransac`、`gaussian_process`。运行中改变已声明参数值会被拒绝，需要改配置后重启。方法也进入平台 Profile 哈希，切换后不能复用另一种方法留下的通行结果。

### 起点补丁是另一条有范围限制的处理路径

起点补丁用于起点附近缺少观测的请求。它的支撑平面拟合和原始支持点过滤共用既有逻辑：过滤调用基线平台评价器，再用认可的原始点拟合一块支撑平面。补丁把这块平面上的假定高度放入单独的请求级视图，已有真实测量仍优先使用，不向全局原始高程图写入假定值。

随后，`FineCellEvaluator(patched, capability, profile)` 会按当前选定的拟合后端重新评价这个假定视图。因而不能把整个起点补丁说成固定使用基线：共用的是支撑平面、补丁范围和起步阶段规则，最终评价仍受到所选方法影响。通过的请求级格子保留 `kStartAssumedFree` 来源标记，不能视为新的真实测量。

在假定视图中，`ElevationRangeAt` 也返回假定高程，这些可用点会进入背景的初始点集及计数。此处 `observed_count` 不能解释成原传感器测量数量；假定必须保留请求级来源，不能当作全局真实观测。

主合成集成探针直接使用没有覆盖格子的 `RequestLocalPlanningView`，没有调用起点补丁构建器；它比较的是通常的通行图与局部路径。其他实验若启用了起点补丁，需要单列起点救援是否成功及假定格子数量，避免把补丁作用归到候选拟合方法本身。

## 9. 如何阅读实验结果

对比报告需要把两个层次分开：

- **拟合层：** 在同一组邻点上，模型的高度和梯度误差、离群点处理、MLS 回退情况和模型计算开销。
- **系统层：** 共用检查之后接受多少补值、是否出现错误放行、平台通行状态与路径是否改变，以及完整计算耗时。

例如，MLS 可以更准确地表达一个二次曲面，但若该曲面的原始局部突变超过共用门槛，系统仍会拒绝补值。GP 可以降低模型内的不确定性，但若额外评分衰减使更多位置被拒绝，系统覆盖率也会改变。RANSAC 可以分开两个不连通片段，但这种能力不会自动发现没有测量证据的所有沟。

因此，算法的表达能力、当前参数下的实验表现和最终车辆安全是不同层次的结论。本文给出实际实现与参数，具体比较和结论以完成后的同输入对比报告为准。
