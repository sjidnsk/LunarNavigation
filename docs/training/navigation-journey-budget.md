# 训练仿真的导航行程预算

单次请求包括接单、规划、运动、转向和结果返回，不能把全部过程限制在120秒。
训练环境现在以 `max(120, 1.5 * L / (0.2 * R) + 30)` 秒作为行程预算。

- L优先来自当前任务的全局路线，包含绕行；尚未收到路线时使用起终点距离作为下界。
- R是物理积分累计时间与墙钟时间之比。至少采集3个一秒窗口，以最近5个样本的中位数估算；配置的目标倍率只作为初始值和上界。
- 同一次请求的计时起点固定。预算可以随更长路线、较低实测倍率增加，但不因倍率恢复而缩短。
- 使用最大已收到路线长度，不累加重复滚动参考或已行驶距离，防止来回循环不断延长预算。复杂动态重规划的总实际路程可能超过该估计，1.5倍余量并不保证容纳任意次数绕行。

独立保护：接单10秒、当前会话导航/控制反馈中断15秒、连续等图15秒、无0.1米位移或0.1弧度转向进展60秒。运动进展允许绕行和原地转向，不要求靠近目标；角度差正确处理正负π边界。地图刷新、其他任务的诊断及重复全局路线不能充当当前任务反馈；旧控制状态不能遮住更新的等图状态。

失败时在实验的 `navigation-watchdogs` 保存目标、实际位姿、预算、倍率、路线、会话/执行状态和所属子进程。错误代码区分行程耗尽、无进展、等图及反馈中断。它们仍属于基础设施执行失败，不改写成探索策略失败或训练奖励。

此修改只影响训练仿真的执行监督层，不改变地图、全局/局部规划器、探索决策、网络、回放或到达容差。可用独立DDS域运行受影响的适配器测试和真实闭环验收；不得占用正式训练180..187、评测216..223。
