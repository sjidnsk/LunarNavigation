## 已知与未知

| 判断 | 当前证据边界 |
| --- | --- |
| 奖励/折扣 | gamma=1，排除按步折扣衰减；后期仍有收益弱、通行成本累积现象，未证明奖励目标是唯一根因 |
| 一步TD | 使用真实单步奖励和下一状态软价值估计；并非只看眼前，收益传播慢是待验证假设 |
| Actor与Critic排序 | 已捕获差异；Critic有真值信息且Q仍为估计，逐隐藏状态不一致不等于Actor错 |
| 双Critic | 旧A现场对离环动作排序相反，新A现场同向；同向不等于真实回报校准正确 |
| 局部Actor拟合 | 两状态、新Adam、固定Q下能改变选择；不证明混合回放下的泛化，也未排除信息不足 |
| 动作与图 | 已捕获场景有合法离环候选，Actor有整个测量图；尚不能把循环归因于出口被删 |
| 表示能力 | 历史二值位可饱和，远端机会可能超过6层局部传播；仍有全图读取，未证必须加RNN/加层 |
| 随机采样 | 第一轮模型额外采样回合仍长期停滞；不能仅换选择方式就声称解决 |

Actor应优化其可见信息下的期望收益；不能要求它逐样本匹配掌握隐藏地图后的最优动作。
Critic只直接拟合执行动作，而Actor更新参考全部候选，因此罕见候选高Q还可能是外推误差。
当前TD后续动作由`Actor(next_observation)`加权，没有使用真值贪心策略接管未来。
相近输入不等于严格相同观测；把真值特征随意清零也不能构造有效的信息差反事实。

  若需要比较再次返回A前后的输入，应提前规定有限捕获窗口；已有单transition不能冒充A→B→A完整证据。
- [ ] 对齐候选物理位置、朝向和合法性，不能跨图直接用action序号当同一个动作。
- [ ] 先看真实执行支持、双Q一致性及可见信息相近样本的评分冲突。匹配不足就记录证据不足，

- [ ] 有稳定且可观测的优势证据后，再做固定Critic的训练/留出检验，区分拟合和泛化。

现有冻结transition不是可恢复的完整仿真状态。若还需要动作反事实，另定义可以重置并保持
观测历史一致的有限探针；不能把不同重跑轨迹冒称同一状态下的因果比较。
本阶段不以“所有机制必须唯一归因”为无限调查目标：完成限定审计后，选一个证据最充分、
可证伪的假设进入对照；若证据仍不足，报告缺口和下一个最小探针，不反复加训。

### 3. 根据证据选择一个训练改动，最多两臂

| 主要证据 | 首个候选实验 | 暂不同时改动 |
| --- | --- | --- |
| 连续片段显示回报传播是主要疑点，且数据契约可支持 | 1步基线 vs 最大8步的短序列目标 | 奖励、gamma、Actor结构和优化器频率 |
| 价值优势有支持、可由观测判断，策略在留出状态仍学不到 | 策略拟合/样本利用的单因素实验 | Critic目标、奖励和图输入 |
| 失败与缺少可见通路关联或丢失已观测历史一致 | 一个最小部署可见输入/读取改动 | 奖励、回报跨度、额外运行时选择规则 |
| 高Q缺乏执行支持或双Q矛盾 | 先做有限估值校准与行为支持诊断 | 不直接把该Q变成硬标签强教Actor |

8步是试验候选而非已证最优，也不是每8步才更新或必须等整个场景结束。
多步若被选中，必须先形成具体实现设计：连续片段不跨环境/重置，真实terminal停止bootstrap，
预算/停滞truncated保留bootstrap，处理SAC熵项及历史行为策略差异。旧Transition没有行为动作概率，
不能凭actor_version伪造；旧经验维持兼容的一步目标，新数据最小补齐所需元数据。
首轮只比较1与8，有趋势后才考虑4或16，不同时展开参数网格。

共同条件：从同一个25320完整检查点开始；参数结构不变的实验保留模型、目标网络、Adam、alpha、回放、RNG及credit。
若改变输入或参数结构，先规定受控迁移、新增参数初始化、旧参数及优化器状态的保留方式，
单独验证两臂初始输出的一致性；有意改变的部分明确列出，不能称为完整原样恢复。
60 m采集、同一预定场景种子安排，每臂最多2048新增。保持batch64/microbatch8和0.25更新比率，
但还必须核对实际新增更新数与起止credit，不能从2048直接假定更新512次。
若现有实验入口不能保证声明的共同条件，先补入口及相关测试，再开始对照。
两臂收集的具体轨迹会随策略变化，不能声称逐转移相同。

## 存储与执行约束

现有`artifacts`预算、原子写入及执行锁继续使用，不建立独立嵌套额度。
保留当前完整25320共同起点；历史模型只留现有小Actor和摘要。后续两臂顺序运行，各一个滚动检查点。
顺序运行仍要计入“起点 + A + B + 原子保存临时B”的同时占用；按当前完整快照大小会超过8 GiB。
若进入两臂训练，先把两臂落盘回放快照上限同时按1 GiB做实际峰值预检，峰值不满足就不启动。
这不会缩减从共同起点恢复的初始内存回放；若中断后恢复较小快照，回放会变化，不能继续冒称
严格同条件实验，应从共同起点重跑该臂或降低结论等级。不得自动删除旧失败证据换空间。

不保存全地图、视频、无限轨迹、额外完整模型历史；诊断只保存有上限的摘要和失败现场。
每完成一阶段先写结果及下一步决定，再进入下一阶段，不自动续开第三轮、参数网格或大图长训。
