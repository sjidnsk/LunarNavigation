# 目标网络更新速度的有限对照

## 问题、选择与边界

依据[第二轮冻结评测与真实窗口审计](2026-09-27-drl-phase2-frozen-evaluation.md)，
当前真实负收益往返的目标soft V高于在线soft V约0.604—0.681，足以改变TD拟合方向；
同时在线残差、双Q分歧和Actor概率集中仍存在。选择检验“目标网络更快跟随在线网络是否能改善循环”，
不把它宣称为唯一根因。0.02是预先固定的四倍更新系数，不是已知最优值。

替代方案：1步与8步需要先补序列及离策略/熵契约，当前窗口没有完成收益传播证据；
直接强教Actor又依赖未校准Q；同完整仿真状态的动作反事实需要现有transition不具备的重置能力。
本轮因此只做一个参数对照，不加运行时动作规则、不改奖励或输入，也不另造完整仿真快照机制。

本仓库`target.lerp_(online, polyak)`的系数是在线网络的混合权重：
`target <- (1-tau)*target + tau*online`。与[Spinning Up SAC文档](https://spinningup.openai.com/en/latest/algorithms/sac.html)
中旧目标的权重rho互补，不能把0.02误读为98%的在线权重。
算法背景见[SAC作者论文](https://arxiv.org/abs/1812.05905)；它们不为本项目0.02提供效果保证。

## 已固定的对照条件

| 条件 | 基线 | 实验 |
| --- | --- | --- |
| 共同来源 | `run/resume.pt`，102308条/25320更新，SHA0149887d… | 完全相同来源 |
| Polyak系数 | 0.005 | 0.02 |
| 新增入库上限 | 2048 | 2048 |
| 采集 | 60 m、512步、8环境，原训练停滞限制 | 相同 |
| 学习 | C0、gamma1、原奖励、lr1e−5、batch64/micro8、update ratio0.25 | 相同 |
| 初始状态 | 保留在线/目标网络、Adam、alpha、回放、RNG、credit | 相同，仅学习配置tau不同 |
| 场景安排 | 现有paired_slot_episode_v1，原seed与env数量 | 相同槽位/回合种子序列 |
| 落盘回放快照 | 1 GiB | 1 GiB |
| 输出 | 根下`polyak-baseline` | 根下`polyak-fast` |

两臂均顺序运行、单根执行锁；每臂7200秒、控制器16000秒上限。
实际轨迹、不同环境完成回合数和回放采样内容可因策略而不同；相同场景安排不代表逐转移相同。
源回放全量恢复至内存，1 GiB仅限制新落盘快照。任一臂中断或数值/基础设施失败即停止整个对照，
不自动从较小快照续训。两臂更新数按起止credit和0.25新增比例核对，不预设必为512。

原25320共同起点只读，不复制、不覆盖。总根8 GiB、诊断128 MiB继续生效。
峰值预检包括现存文件、两个臂检查点、原子写入临时检查点、诊断剩余额度和小Actor；
以源文件扣除实际回放字节后的余量估算非回放序列化，再给每份128 MiB余量。
训练写入仍受真实预算限制；检查失败不删除历史证据换空间。

## 提前规定的效果验收

1. 两臂新增预算和实际更新量可比、无丢失credit；共同恢复身份相同，完整源SHA未变。
   若不满足，不给算法优劣结论，不自动补训。
2. 固定面板记录target-current差、单步残差、候选Q及离环概率，作为机制指标。
   面板仍来自原25320行为，不能当新Actor真实轨迹或离环真实回报；差距缩小本身不是成功。
3. 两个新Actor均冻结、joint argmax、关闭训练截断；先运行原4张开发图（2701/2702×cave/moon）
   加已转为开发案例的moon2703，共每模型5回合。看99%完成、持续零新增往返、成功回合步数/路程、碰撞。
   绝不使用当前24808充当本次训练基线。
4. 若关键图仍失败、原成功有退化或相对本次0.005训练臂没有行为改善，报告本轮不支持该方案，停止扩训/叠加调参。
   两臂同时优于旧25320并不证明0.02优于0.005。若通过，使用此前未用于训练选择的新地图种子2026092705/2026092706×cave/moon各4回合。
   原2703/2704结果不再作为新的泛化留出。
5. 单次关键改善存在ROS轨迹波动：最多选择2张关键地图，每模型再跑1次；不一致就保留不确定，
   不无限追加样本。整体最多22个正式回合（10开发、8新种子、至多4复核）；诊断探针不混入完成率。

结果待本文件随实际执行更新。Humble、Orin、实车、大图及本实验效果目前NOT_RUN。
