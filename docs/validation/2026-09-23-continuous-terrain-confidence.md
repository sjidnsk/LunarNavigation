# P4 20 cm 邻域估计与连续地形可信度

日期：2026-09-23。承接首版 `2026-09-23-basic-terrain-confidence.md`。本轮用户确认：保留 5 cm 输出，按 20 cm 尺度组织邻域观测，可信度为连续值。只修改 P4；P3、尺寸、运动能力、真实障碍碰撞约束不变。

## 实现

使用物理尺度的滑动邻域，避免固定粗格边界导致估计跳变。缺测格支持搜索每轴最多 0.20 m，最近真实样本距离不超过 0.20 m，全部读取仍位于原有地形背景窗口内（足式半宽 0.20 m，轮式半宽 0.40 m）。适用于输入分辨率不超过 0.10 m；P4 不重采样 P3 输入。

不再要求八条精确栅格射线上都有回波。至少四个原始样本、非退化平面，并且样本角度分布包围查询点；不从单侧或一条扫描线向外补。逐步寻找最小充分邻域，保留近处地面，避免远处台阶污染小孔洞。背景最少真实样本从九个改为四个，仍需双侧空间分布与非退化拟合。

平面估计的高程区间端点最大残差不超过 0.03 m，拟合坡度仍受平台坡度限值约束。0.03 m 是观测一致性阈值，不是台阶/障碍允许高度。原始观测不覆盖、不平滑；估计值不递归作为新证据，也不能单独作为终点、落足或盲区出口依据。

推断可信度计算：

```
c = 0.85 × (0.5 + 0.5 × min(1, 样本数 / 8))
         × (1 - 0.5 × 最近样本距离 / 0.20)
         / (1 + 区间端点拟合RMSE / 0.01)
```

低于 0.20 的估计不接受，保留 UNKNOWN / 0；直接观测充分支持的判定为 1；推断为连续分数，最高 0.85。它是工程证据分数，不是校准的通行概率。数值阈值需要后续真实传感器回放验证。

整机范围取最低可信度；存在硬障碍先判 BLOCKED，存在无法补足的区域仍 UNKNOWN。代价继续增加 `confidence_weight * (1 - confidence)`，默认权重 2。快照由一位推断标记改为每格 float，保留连续分数；零权重下分数变化也使增量快照更新。每格可信度存储从约 0.125 字节增至 4 字节。

三部署分支同步观测与连续可信度处理。轮式分支保留原有未部署的旧足式算法，仅给其已知结果补齐 1/0 可信度，不移植足式部署算法。实车轮式与 TCP 轮式修改一致。

## 验证范围与行为变化

新增六项测试覆盖：20 cm 规则采样支持 5 cm 地面、连续分数随质量变化、零权重下小数分数变化与全量/增量一致、单侧/共线/矛盾证据拒绝、非法分数拒绝、稀疏实测台阶和下陷不能变为 FREE 通路。保留原有尺寸、坡度、台阶、障碍、路径代价偏好及路径简化回归。

原“整条一格缺测必 UNKNOWN”测试不适用于新需求：宽度小于邻域范围的无回波细条，在周围一致地面支持下现在可以推断。这并不能识别没有任何回波证据的隐藏窄坑。测试改为超过推断范围的连续空白带，并保留有实测高差的细障碍/台阶约束，不能将这一行为变化描述为“所有缺测沟槽都可识别”。

测试先复现旧机制无法通过两个新增稀疏/连续分数用例。全量回归还发现轮式分支旧足式评价未填写可信度，导致已有平地代价和搜索测试失败；已补齐旧评价的 1/0 分数，保留其物理行为。ROS 首次运行因缺少消息库路径失败，补齐 CMake 指向的 Jazzy `lunar_planning_msgs` 库目录并安装本轮 ROS 库后重跑。失败日志保留在仓库外产物。

本机验证结果：足式核心 316 项 / ROS 100 项；实车轮式核心 302 项 / ROS 100 项；TCP 轮式核心 302 项 / ROS 96 项，合计 1216 项通过。ASan/UBSan 地形、连续可信度、起点盲区三组 53 项通过。首次 ASan 构建使用了不存在的目标名，改为实际的 request_local_start_patch_test 后重新构建并验证三组。未修改 launch/ROS 参数接口，本轮未重复纯启动配置测试。

地图对照图已按最终库导出，保留 P3 原始高程，P4 置信度使用 float32；这帧 27 个推断可通行格的分数范围为 0.27587～0.52000，共 7 个不同分数，不再量化为 0.5。浏览器浅色/深色、1024/736/360 px、地图缩放及悬停检查通过。
