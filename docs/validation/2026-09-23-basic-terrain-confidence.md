## 当前机制

- 可通行性继续使用 FREE / BLOCKED / UNKNOWN。可信度仅为工程等级：实测支持的判定 1.0、使用合格邻域估计的可通行地面 0.5、无法判定 0。它不是通行成功概率，不是完整的定位或传感器误差模型。
- 保留 P3 原始输入分辨率和原始高程；5 cm 输入仍为 5 cm。不会从粗网格制造真实细观测。
- 邻域估计只针对中央局部缺测。复用原物理背景窗口，按每轴最大 0.10 m 限制估计支持搜索，且所有读取都位于原背景窗口内。逐步扩大至最小足够邻域；八个栅格方向分别需要在范围内找到真实观测，不再要求八个立即相邻格齐全。至少 8 个原始样本、非退化平面，所有参与高程区间端点距拟合面不超过 1 cm，并满足平台坡度限值，才能估计。
- 这是受限的基础实现：不能解释的大片缺测、连续方向缺测、地形矛盾仍保留 UNKNOWN；不具备识别所有被遮挡坑洞的能力。没有为了提高可通行比例继续扩大推断范围。
- 估计值不写回原始高程，也不能递归充当新观测或高低表面支持证据。保留真实障碍与各平台尺寸/运动约束。
- 整机范围只要含合格推断地面，就取 0.5；存在真实障碍仍 BLOCKED，存在无法解释的未知仍 UNKNOWN。不能只看机身中心是否有高程。
- `IntrinsicTraversalEvaluation` / `FineCellEvaluation` 返回 confidence；地图快照提供 `Confidence(index)`。每格只增加一位推断标记，其他等级由状态恢复；不引入多套可信度图层或修改 ROS 地图消息。本次没有新增可信度可视化话题。
- `confidence_weight` 默认 2.0，进入 profile 哈希和快照权重，启动时可覆盖，必须有限且非负；运行中修改拒绝，需要重启。三个部署入口及 TCP 的 P4 联调模板显式一致。

代价：`原有地形代价 + confidence_weight * (1 - confidence)`。默认下，平整高可信地面新增 0，中可信新增 1；UNKNOWN/障碍仍硬拒绝。权重设为 0 只关闭额外代价，保留可信度、邻域估计和碰撞约束。

推断格沿用上一轮的证据隔离：不能单独作为导航终点、真实落足支持或起点盲区出口；原有起点假设机制保持独立。

## 保证最终路径真正受代价影响

新测试复现了旧路径简化会把绕行重新拉直的问题。轮式简化在保留原碰撞/净空检查外，要求捷径的保守地形代价不超过被替换原路径。同一条边按长度乘以沿 supercover 格子的最大地形代价系数计算比较值，保留取消和超时检查。

足式部署的边代价读取沿边最大地形代价，避免只看终点漏掉中间推断区；足式简化也增加一致的代价比较。两个轮式分支只同步其部署使用的轮式处理，不搬迁旧足式规划实现。这项简化保护也适用于原有地形软代价。

新观测消除推断后，可信度能由 0.5 变为 1；即使权重为 0、状态和代价均不变，推断标记的变化也会产生正确的地图更新。历史真实高程积累、状态/代价缓存均保留。
