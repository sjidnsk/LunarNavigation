# 平滑补足地面与有效规划高程接入

## 需求与职责

用户确认平滑补足进入通行评价，并进一步明确：可信度足够的补足高程必须作为有效高程参与起点、落点和路径检查。早期“推断仅可经过、不能作为终点/支撑”的约束已被此决定替代。P3 不修改。轮足共用观测估计，平台尺寸、步高、坡度、车底及真实障碍碰撞约束保持各自配置。

## 实现

- 有限自适应邻域：默认轴向半宽20cm，依次缩小到一格，失败再扩到30cm；到真实支持观测最近距离仍限制20cm，缺测补足限≤10cm网格。仅原始数据参加稳健平面拟合，禁止推断递归反哺。首个合格邻域策略尚非最优窗口选择算法。
- 连续可信度来自拟合一致性、支持样本和距离；原始区间、孤立高度突变、邻接突变/二阶差分仍受保护。坡度读取连续地面估计，原始区间仍用于真实台阶和障碍检查。
- 足式精细格的中心地面已有足够支持时，不再要求周围3×3重复完整证明；整机覆盖仍逐格检查未知/阻塞。轮式部署分支原有独立足式实现不被替换。
- FineTraversabilityTile 保存按版本生成的地面高程。PlanningElevationRangeAt 保留直接观测区间，在缺测且FREE/正可信度/有限地面值时使用推断高程。raw elevation保持只读且可区分来源，可信度参与代价。
- 起点/终点/足式支撑以及路径边的步高和缺口检查统一读取有效高程。起点盲区临时假定仍与真实/推断地面分离。
- 地面变化参与增量 tile 更新，即使状态和代价不变也不能遗留旧高程。新增持久数据每格4B；最大邻域半径参与增量依赖。构造参数改为常量引用，避免大数组重复栈拷贝。
