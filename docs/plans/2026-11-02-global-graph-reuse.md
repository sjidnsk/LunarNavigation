# 大地图全局规划构图优化与Smac2D对照

目标：保持现有Route/WorldSnapshot接口与全局-局部-执行职责；优化真实构图超时，不修改安全边界或总预算。

1. ROOT保存当前现场地图/目标与旧源码，固定冷/暖/地图变化基线。
2. 独立实现子任务：分析构图热点；空间障碍查询；按需边认证/代价；持久worker内可界定缓存复用。不缓存起终点和过期障碍证明。逐项回归与性能计数。
3. 独立对照子任务：Humble Smac2D原生实现离线入口，相同场景/碰撞半径/允许UNKNOWN/软偏好含义；报告栅格近似和代价差异，不宣称严格等价。
4. ROOT代码/职责/失效边界复审，重放冷启动、相同图多目标、局部变图、尖角障碍、预算耗尽。
5. 首批通过后按用户授权备份并替换P4，只重启P4；P3和Env_X不改。Smac仍仅离线。
6. 显式文件提交、任务登记及验证边界记录；不push/长期线合并。

复审重点：缓存不能复活旧图路线；更新障碍后的碰撞仍连续检查；软代价索引不能漏50cm内障碍；起终点变化必须重连；有界预算及缓存内存；首次与重复性能分别报告。
