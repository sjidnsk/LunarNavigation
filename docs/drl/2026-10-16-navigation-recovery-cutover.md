对照原目标的试验实际执行原来的两次初始化转向，以保证观测方向可比。正常运行的初始化参数没有变化；修正后的支持可能更早满足就绪条件。

## 实施判断及限制

| 判断 | 原因 | 判断错误时的代价 |
| --- | --- | --- |
| 公共回归使用独立高度 fixture，实际测量 fixture 留在 DRL 开发线 | 集成主线没有 DRL 专用测量接口 | 公共回归可能不能覆盖某个 DRL 特例，因此另保留实际捕获地图回放 |
| 控制器保持原样 | 两个核心修复后原目标和停车恢复已通过 | 未覆盖的短段跟踪问题仍可能出现，保留真实执行记录定位 |
| 仅在匹配诊断中重放原初始化旋转 | 保证原目标已有相同方向的真实观测 | 不同观测量可能被误判成规划回归，因此正常 Actor 试验另外验证 |
| 共享几何检查继续响应取消和期限 | 防止路径处理绕过受控终止 | 漏检可能拖长取消响应，单独期限回归覆盖 |
| 仅测试 runner 增加栈到 64 MiB | 既有 snapshot fixture 使用较大局部数组 | 不能证明生产默认栈行为发生改善，生产参数不变 |
| DDS/IPC 用隔离域在宿主权限下复验 | 沙箱拒绝本地通信不能代表算法失败 | 不同环境仍可能有中间件差异，Orin 和实车单独标识 |
| 候选建立新源码清单周期，激活前旧身份仍权威 | 防止身份标识掩盖代码变化、混用历史评测 | 错误身份可能使评测无效，以不可变审计及文件 SHA 校验 |
| 只修正信号测试夹具握手 | 优化模式删掉 fixture 内 assert 中的阻塞 I/O；旧正式包也复现并在修正后通过 | 可能掩盖实际原子更新问题，因此保留旧包复验及计数一致性证明 |
| 用户通知后重新验证已保存边界，再暂停评测 | 原守候按用户要求已停止；此时 trainer 已自然结束 | 若错误判断阶段，可能中断下一块，因此核对了精确计数、trainer 不存在、评测阶段和 checkpoint 不变 |
| 保留第一版候选、旧分支和工作树 | 保留实验来源和回退依据 | 多占用磁盘；不影响正式训练参数和当前运行环境 |

Orin 原生硬件、实车、外部 TCP 仿真服务本轮均为 **NOT_RUN**。上述验证证明修复和运行状态连续性，不证明模型已经学会任务入区或已经收敛。
