# 导航执行安全与1厘米连续绕角修复

固定模型评测暴露两类问题：053理想参考仅有3.34毫米净空，控制跟踪偏差可穿过真实禁行格；012/054/085存在对准与追踪几何不一致引发的重复转向。修复保持公开目标到位标准0.10米/0.05弧度、模型权重、奖励和覆盖率定义。

## 最终行为

- DRL执行器闭线段supercover与原生导航一致，保留角点接触及禁行边界拒绝，消除先前误检查未经过旁格的问题。
- 轮式局部搜索、终端连线和路径简化检查额外1厘米连续几何净空；未知及窗口外空间同样保守处理。严格原地转向使用原有stationary支撑认证，不复用为平移许可。
- 绕角中间点可以在连续空间调整；每次接受前重新认证两条完整相邻线段，保持端点、phase和终端朝向约束。
- 对准、追踪与重新转向使用同一lookahead弦；短尾段对准受曲率可行性约束。浅绕角也需停稳切换，共线采样点透明。
- 中间到位容差受余量四分之一约束；误差调节速度，保持v/omega联合限幅；制动距离包含0.15秒响应预算。该调节律不等于完整动态扫掠/刹停安全证明。
- 停稳执行拒绝单独计数，无位姿/地图进展时三次拒绝结束，避免不断重规划。新的观测、运动进展或新会话可重置预算。
