# 四阶段探索课程

用户确认：区内月表 → 区内洞穴 → 区外月表 → 区外洞穴。一个 SAC，阶段间完整继承 Actor、Critic、优化器、replay 和随机状态；新实验从零初始化，保留旧混合训练和 26856 基线。无位置辅助损失，不改导航、奖励或模型输入。不计算可探索面积；保持 50–100m，决策预算按原面积插值 256–512、32步取整。

任务标签固定为 moon_inside、cave_inside、moon_outside、cave_outside。当前任务新增转移及 replay anchor 采样目标 80%，旧任务合计20%（等分）；首阶段100%。按完成转移计配额，不按环境或回合计比例；允许有限在途误差，记录实际比例。每回合标签冻结。区内/外仅约束起点，导航可自由跨界；起点选同一主连通分量，严格按任务多边形分类，找不到合格起点明确失败，不默默退回另一类。

每个训练块新增8192转移，约2048更新，预热1024。每块冻结Actor评测：当前任务5个场景，后续阶段另加5个旧任务场景（轮换均分，最多10）。固定地图尺寸50、61.111、72.222、88.889、100m，种子与训练分离；明确起点模式并纳入结果、缓存身份和配对身份。同轮Actor一致，不复用旧语义结果。

默认升级门槛：连续两块当前任务至少4/5无碰撞99%完成、当前任务两点循环步数总占比不超过20%，旧任务池至少80%成功。月表阶段最多20块、洞穴最多10块；到上限未达标保存后停止，不强行升级。门槛和上限写入独立课程计划，恢复不重复升级、不篡改计划。保留独立验证与本机Jazzy范围。

终端逐场景覆盖率及成功数量保留，增加四任务回合/转移/采样占比/平均回合步数。学习、固定状态、完整评测、奖励CSV/PNG继续记录；新增课程统计CSV。区内外按回合起点标签统计，不能随机器人跨界变化。
