# 稀疏图消息聚合计算提速

本轮针对用户“先做计算提速”的要求，仅优化现有稀疏图注意力的消息聚合计算。运行源码在 `perf/drl-message-aggregation-20261013`，起点为 `8b0b6319598d0ef7735ae804ba9da1ce3f61a4af`。原区域查询分支及其未提交的终端界面改动保留。

## 改动及边界

原计算先读取每条边的源节点向量，再乘注意力权重，最后按目标节点累加：

```python
messages = weights[..., None] * values[source]
output = messages.new_zeros((count,) + messages.shape[1:])
output.index_add_(0, target, messages)
```

新增 `edge_message.py` 将同一表达式交给 `torch.compile(fullgraph=True, dynamic=True, options={'compile_threads': 1})`，减少大规模逐边中间张量和独立内核开销；`model.py` 只替换该表达式的调用。已有边点积融合保持启用。CPU与显式确定性模式保留原实现。

不新增可学习参数，不改变图节点/边、图压缩规则、Actor/Critic网络、奖励、折扣、采样比例、优化器、FP32精度、batch64/microbatch8、6层激活重计算或12个环境。编译兼容性异常只警告并回退一次；直接及常见包装的CUDA执行错误、OOM继续上报。首次编译/预热开销与稳态计时分开。

这验证的是同一数学表达式在浮点容差内的实现一致性，不是CUDA逐位一致或长期学习轨迹相同，也不表示策略已经更会接近任务区域。
