## 终端面板

建议窗口 144×42；也支持 80×24 的紧凑显示。顶部状态、分页、底部操作键固定，长内容可滚动。

| 按键 | 页面 / 操作 |
| --- | --- |
| 1 | 总览：流程、当前阶段进度、估计剩余、资源、场景分组、活动任务 |
| 2 | 并行任务：完整任务表、每路 PID、阶段步数、覆盖、耗时、指标年龄、传感器、场景重试原因 |
| 3 | 训练与采样：本段/累计采集更新、保存倒计时、课程成功率、实际接收比例、经验供给、最近一批采样、学习指标 |
| 4 | 评测与门槛：新任务、旧课、D1–D8、初始化、四项能力组，基线比较、首见率、错误与未完成明细、阶段门槛 |
| 5 | 诊断与日志：输出/检查点路径、身份摘要、状态与退出原因、告警、控制器日志末尾 |
| Tab / 左右键 | 切换页面 |
| 上下键 / PgUp / PgDn / Home / End | 滚动当前页面 |
| Q / Ctrl+C | 只关闭面板 |
| P / R | 请求保存停止 / 从允许恢复的状态恢复 |

未开始的指标显示“—/待开始”，不作为 0% 失败。训练成功率分母是已结束且有策略动作的回合；零步结束、初始完成单列。评测完成率分母为有效已结束场景，运行错误另列；从零首见率另外剔除初始可见场景。部分评测不作晋级判断，门槛结论需与完整评测和模型身份一致。

验收合格数来自身份有效的结果文件；控制器需等子进程结束后收回任务，因此两者可能短暂不同。已有合格结果的工作进程显示“结果已合格”，不会再占用分组中的“在跑”计数。验收阶段的步数/覆盖是最近一次前序或可完成性验证指标；前序复演可能暂时不更新指标，标黄表示指标较旧，不直接判定进程卡死。

验收/评测预计剩余由面板打开后近 180 秒的完成速率粗估，至少采样 30 秒且有新增完成项才显示；不同场景耗时有差异。训练页的估计只覆盖当前采集预算，不包括后续保存与评测。主机 CPU/内存每 5 秒采样，显存读取训练自身指标，不轮询 GPU 驱动。
