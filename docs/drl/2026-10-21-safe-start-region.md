# 生成器保证安全起步区域

用户确认采用安全起步区域假设，并进一步明确：应让生成器生成满足安全条件的场景，不能为了容纳旧场景而缩小安全条件。

按用户进一步指定，将原候选 4 米改为 2 米；新模式固定采用 `safe_start_radius_m: 2.0` 作为候选协议。它表示起点周围半径 2 米的机器人中心区域，其所有相交的原生导航格均为 FREE。原生导航图已包含约 0.719 米车体外接圆的硬膨胀，因此对应的实际地面安全范围比车体更大，而非将机器人当作质点。

## 地形生成与接受条件

- 洞穴：在解析地形生成阶段为 anchor 房间预留大于安全圆盘、车体及栅格支持范围的平坦起步室。必要时增加母图嵌入间距，防止扩大房间引入非预期连通。保留母图节点、连边、结构签名及训练/验证/测试分组；解析间距检查和原生房间-走廊拓扑收缩检查仍必须通过。
- 月面：从生成地形主连通分量中筛选满足相同安全圆盘的起点，保持任务内外关系和外部距离带。没有合格起点则拒绝，由原有备用场景资格检查机制重生成，不能降低半径或偷偷使用旧起点。
- 接受依据始终是原生膨胀后的 FREE 地图，不以解析房间大小代替实际验证。圆盘检查采用单元面积的保守距离界，有限地图外部视为不安全。

洞穴起步室的原始地面半径为中心安全半径加车体外接圆半径及六个栅格的离散支持余量；当前约 3.92 米。该解析余量覆盖地形导数模板和栅格相位，最终仍须通过原生圆盘验证。新地形的实际范围可能大于原名义 extent，实际 provided_bounds 和任务多边形必须如实记录。

`reserved_start_region_v1` 是新的生成条件，进入场景 ID、配置/恢复语义、生成描述和每场 reset spec。安全起点重采样不改变种子朝向和传感器。真值验证和预留房间只在离线生成器中使用；不把真值图、保证掩码或安全区边界提供给 Actor。

## 导航与历史兼容

原导航与跟踪算法、车体几何、膨胀、物理限制及起点补全参数保持不变。为运行生成不可变、内容寻址的原能力 YAML 副本，确认其能力与冻结配置相同，且实际原生补丁范围不超过生成器保证半径。原能力文件不被改写。完整能力 YAML 的 SHA256 在配置创建时冻结并进入恢复语义，运行前复核，防止默认补全参数等顶层字段在场景认证后发生漂移。

注意配置来源：已完成评测使用的 wheel.yaml 没有 start_blind_zone_margin_m，原生 LoadPlatformConfig 默认值为 0.2 米，补丁总半径约 0.919 米。源码另一份 wheel_orin.yaml 的 3 米值不能代表这次运行。此前 0.8 米/1米“迁就旧场景”的探针已撤回，不是采用方案。

`safe_start_radius_m: 0` 保留历史生成和运行行为；新模式必须在配置中明确开启，场景参数或描述不得绕过关闭状态。旧训练不能在保持原恢复身份的同时静默开启新模式。

```bash
python -m lunar_drl_exploration.region_relation_prepare prepare \
  --root /absolute/path/to/new-safe-start-run \
  --protocol /absolute/path/to/protocol.json \
  --safe-start-radius-m 2.0
```

该命令只准备新请求，仍须执行原有 `qualify` 完成真实原生观测资格检查。已有 root 的准备半径不允许改变。

旧冻结场景、24检查点的2880场结果和模型保持原样。新条件下的模型结果属于新场景协议，不能覆写或逐场混入旧结果。安全区域先验仅保证初始区域，不证明整场无碰撞，也不代替中途碰撞的独立诊断；短程 ROS 起步回归不等同完整探索验收。不会自动启动新训练、选模、合并、推送或实车部署。
