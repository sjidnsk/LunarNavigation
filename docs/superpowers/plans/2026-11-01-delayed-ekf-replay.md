# P3延迟位姿离线回放对比

用户授权离线原型，禁止部署/修改在线算法。复用NAV-TERMINAL-POSITION-20261101专题，基线c7ddebf，ROOT单写入，方法/结果独立复审。

1. SHA核对既有日志，按COMMAND_STATE_ESTIMATE自身时刻解析；首次看见新P3源戳作为可见时刻。
2. 在未来P3源时刻进行评估，标签仅用于打分。各方法只能使用该时刻之前已出现的输入。在线基线取不晚于该时刻的最近日志预测，间隔<=0.1s，并以其速度外推补齐这小段时间，同时报告间隔；避免将规划完成时间冒充预测时刻。
3. 对比原在线预测、P3保持、P3自带速度恒速、相邻P3差分恒速、五状态延迟EKF。EKF只使用P3 pose更新，在源时刻保存后验、向当前预测副本；不引入轮反馈，不修改参考点偏置。
4. 时间前半段选择过程噪声，后半段冻结评估；固定测量噪声0.5cm/0.01rad仅为实验假设，附敏感性，不宣称P3实际精度。
5. 输出位姿RMSE/P95、终点2cm误进判据、校正跳变、耗时、逐行因果证据及图。P3为参考而非独立真值；源时刻近似采样、原运行命令固定，不代表改控制后的闭环。
6. 补非线性传播/延迟因果/预测不回写后验等最小验证，独立复审结果，提交脚本和方法文档，原始数据/图保存在D盘仓库外。
