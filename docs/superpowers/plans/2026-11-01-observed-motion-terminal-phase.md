# P3实测运动预测与终点阶段确认

> **For agentic workers:** Use superpowers:subagent-driven-development; independent task review and final review.

**Goal:** 降低乐观指令预测导致的误差，并只由P3观测确认终点位置阶段。
**Architecture:** 保留CommandPrediction入口及已有有限历史；由相邻P3源位姿估计实际速度，恒速预测，已有指令仅约束停车/反向/准备等变化，不凭命令自行加速到平台上限。导航使用真实P3状态处理位置完成与10cm越界，估计状态继续用于规划和连续控制；不新增ROS接口/阶段实体。
**Spec:** 用户同意先离线修预测检查异常峰值、统一阶段完成依据、再现场复测。仅P4可写，P3/Env_X只读；定位中心无明确外参不补偿。

## Global Constraints

2cm收敛目标、10cm验收、5度朝向、v0.2/w0.1、持令1.2s不改。无新超时/门禁/训练/地图共享/另一个cmd_vel控制器。源时间推进复用现有高水位，重复帧不确认新证据。保持任务完成已有P3停稳确认。
