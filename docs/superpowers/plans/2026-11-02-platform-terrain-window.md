# 平台尺度地形窗口实施

已批准：坡度窗口跨度L=平台x/y长边；半径ceil(L/(2r))；台阶/局部高差初期跨度L/3；阈值由能力配置读取。TCP阈值已20度，实车轮式暂不配置；不改变碰撞包络和地图三态。

批1 core：唯一批量/标量工具，完整平台方窗内横纵梯度滑动中位数、滚动统计，局部指标不低估台阶；wheel/legged阈值沿旧evaluator复用，仅旧接口保留legacy3x3兼容。新增数据源明确忽略旧3x3标量。用新测试对照旧baseline编译RED，再ARM执行GREEN和独立审查。
批2 输入链：NativeTerrain创建扩展表达平台类型/尺寸，旧三参数ABI仍兼容但新配置不可静默回退；源更新影响半径与窗口一致。探索、core FineCellEvaluator、PolicyMapExporter共用同一工厂。脚本/接口无额外任务实体。
批3 验证：平地、5/10/20cm坡面20度边界、台阶临界值/斜坡台阶/尖点/负坑、NaN/边缘/旋转/大坐标、源滚动和更改halo、导航/探索同源。实采高程旧25.30度邻边回放。16/64m、5cm计时及RSS；逐项记录慢项和NOT_RUN，不靠取消认证或放宽阈值。
批4 收尾：独立复审，UTF8及diff检查，本地显式提交与任务登记；本轮不自动合并、push、实车部署。TCP正式切换按当前任务状态及授权边界处理，不打断未知任务。

执行记录：新窗口core20/ROS11/native80、非异常core25项通过；2异常输入隔离回归仍中止，旧factory对照也复现。用户授权正式候选已替换P4，车辆闭环因缺P3定位NOT_RUN。性能R3独立21core/80native及151956格测量位级等价通过，尚未再次部署。验证文档记录准确范围，不把5cm足式的20cm合成测试当部署要求。专题本地保存待长期线审查，不自动merge/push。
