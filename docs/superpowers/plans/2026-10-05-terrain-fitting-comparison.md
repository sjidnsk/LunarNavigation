# 可信度地形拟合五方案对比实施计划

用户已授权分别实现四种改进并完成充分对比。本任务在可信度专用开发分支执行，不同步应用分支或部署车辆。

## 实施与冻结原则

1. 保留当前 baseline，增加 weighted_plane、mls、grouped_ransac、gaussian_process 可选后端。
2. 各后端只读取原始高度区间。使用相同补值半径、原始极值、局部跳变、包围支撑及平台约束；不得把预测当作观测再次拟合。
3. 加权平面使用距离及高度区间宽度代理测量质量；MLS 使用稳健二次曲面并在秩不足时回退；RANSAC 提取并分组局部平面；GP 使用稳健平面均值与有上限的局部核模型，输出条件预测方差。
4. 公共默认仍为 baseline。拟合选择进入 profile hash，避免增量缓存混用。ROS 启动参数也提供选择，参数错误必须拒绝。
5. 所有参数先固定，再生成相同真值/缺失/噪声输入供五方案比较。保留全部失败、拒绝和超时；不得用真实答案选参数或滤掉困难样本。

## 验证

- 数学单元测试：平面、曲面、退化支撑、离群点、两个面、确定性、预测方差。
- 集成回归：默认算法原测试、方法切换与增量缓存、轮式和足式平台规则。
- 批量实验：解析地形、缺失率、噪声、离群、扫描条带、距离稀疏、遮挡、隐藏沟；至少五个种子，同输入配对比较。
- 报告接受覆盖率与条件误差并列，分场景可信度排序，解析危险区域错误 FREE、密集地图软件参考、路径及运行时。隐藏沟是必须保留的反例。
- 本机 Jazzy core/ROS 构建与完整串行测试。Humble、Orin、真实传感器、DDS、车辆为 NOT_RUN。
