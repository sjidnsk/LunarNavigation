# 课程二：10–50 m 接近与逐回合固定传感器

用户于 2026-10-11 确认方案，并随后将传感器量程上限改为 30 m；本计划中的需求即本次 Spec。

## 目标与约束

- 从冻结的 block31 完整状态开始，保留先前模型、60 场开发结果与暂停的运行目录。
- 月表区外、月表区内、洞穴区内三类新回合均匀派发；12 个进程共享队列；学习仍按三类 21/21/22、回合均匀抽样。
- 新区外月表起点到任务多边形边界的直线距离 10–50 m。扩展地图上下文容纳起点，保持任务尺寸 30–100 m 和自然地形，不用无限远起点。
- 三类场景均使用逐回合固定传感器；量程 10–30 m，视场 60/90/120/180/360°。每五回合一回合保留 10 m/90°，其余在 10–20、20–30 m 两个等宽量程段均衡组合视场并随机取量程。传感器不在动作间变化。
- 不增加人为接近/覆盖/收尾或返回任务，不改网络、奖励或导航算法。
- 固定开发集仍 60 场，每类 5 场沿用原开发集场景、15 场覆盖 10/20/30 m × 五种视场。训练种子与开发种子隔离。初始已完成单列，不计策略成功率；初始可见不计从零首见率。开发集不是论文独立测试集。
- 启动流程为新开发集 block31 评测 → 必要零更新补采 → 2048 条/512 次更新 → 同集评测 → 保存待复核。保留暂停/恢复与终端监看。
- 不提交、推送、合并或清理已有工作。构建和日志放仓库外。旧配置默认语义保持可读，新增配置版本禁止静默混合恢复。
- 实现裁定：完整旧经验池保留，但新学习索引仅纳入本配置的场景，避免旧数据压过新传感器分布；本课程自身的 20% 原传感器回合用于保留能力。代价是零更新补采需补齐全部三类。

## Task 1: 场景、传感器配置与恢复身份

Interfaces: fresh_scene -> RosExplorationEnv.reset -> reset_scene；TrainingConfig -> resume_semantics。

1. 为新配置版本、传感器覆盖及确定性恢复、真实距离/可达性写失败测试。
2. 运行新增测试。Expected: 未实现的配置/距离接口失败。
3. 实现配置档、固定传感器采样、月表上下文及真实边界距离筛选，默认配置保持旧行为。
4. 运行新增测试及相邻场景/课程测试。Expected: 全部通过。

## Task 2: 开发集与评测统计

Interfaces: development_cases -> evaluate_case -> evaluation_gate / panel。

1. 写原场景回归保留、量程视场组合、初始完成剔除和分组退化检查的失败测试。
2. 运行。Expected: 当前代码尚不区分新配置/初始完成，测试失败。
3. 实现 60 场冻结集、实际传感器/距离记录、初始完成单列和原场景回归检查。
4. 运行评测与面板测试。Expected: 新旧统计均正确。

## Task 3: 管理入口与面板

Interfaces: prepare identity -> arm_config -> checkpoint fork；identity -> dashboard。

1. 写新默认目录/配置档传播和面板展示测试，运行并确认预期失败。
2. 接入新目录、范围和传感器配置显示，更新操作文档。
3. 运行控制器、恢复、面板测试。Expected: 通过，旧目录不会被覆盖。

## Task 4: 验证、复核和启动

1. 对新距离带与短/长量程、窄/全向视场做几何验收及本机 Jazzy 原生初始化/动作检查。Expected: 起点合法、观测与输入一致、传感器整场不变；初始完成真实记录。
2. 运行受影响包完整测试和 git diff --check。Expected: 通过。
3. 根据执行计划技能做一次独立代码复核；重要发现经失败回归测试后修正。
4. prepare 新目录，核对冻结源 SHA 与身份，启动 12 路基准评测；重开终端监看，验证实际进程和输出。
5. 更新验证文档与执行账本。启动是本次交付边界，学习效果要等完整评测，不宣称训练完成或优于基准。

## Review Focus

检查高量程下零动作初始完成是否污染成功率；传感器是否贯穿真实观测、策略特征、参考覆盖及回放身份；起点是否按真实多边形距离 10–50 m 且与任务可达；旧配置/检查点是否默默变义；全向与长量程的计算/内存风险；恢复是否重采传感器或复用错误评测；新开发集是否真正包含旧场景回归及全部视场。
