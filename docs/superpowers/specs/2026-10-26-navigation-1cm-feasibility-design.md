# 轮式 1 cm 独立地图导航验证设计与结果

## 已确认的验证范围

- 首轮采用轮式平台。能力参考 `app/orin-real-vehicle@81ed242c496d1d6b40aba17ccc69c46ef9b451e5`。
- 使用独立生成的 1 cm 地图，不接入上游 P3，不加入起步盲区补全。
- 起点完整车体覆盖区为已知自由；全局允许未知，局部是否允许未知可配置。
- 局部轨迹求解窗口以车体中心为中心，5 m × 5 m、500 × 500 格；边界支持数据另行设计。
- 目标可位于地图外、未知或自由区；已知障碍目标明确拒绝。预算耗尽与证实无路分列。

## 模块边界与接口

首版是独立的算法验证包，不修改已有生产导航节点。接口不依赖 ROS；ROS 适配层只能做消息转换。

| 模块 | 唯一职责 | 输入 → 输出 | 禁止承担的职责 |
| --- | --- | --- | --- |
| contracts | 定义不可变数据和轮式约束 | 明确单位及版本号的数据对象 | 调度、搜索、控制 |
| maps | 保存原生 1 cm 稀疏地图，提取局部快照及净空场 | 世界快照、位姿、未知策略 → 500×500 只读窗口 | 修改目标、重规划、改写未知来源 |
| reference | 路线进度匹配和连续前向段提取 | 路线、位姿、旧进度 → 局部参考和新进度 | 避障、速度求解 |
| local_mpcc | 在局部快照上优化状态、控制及路线进度 | 窗口、参考、实测状态 → 候选轨迹或明确失败 | 改写地图、替换全局路线、直接发车 |
| certification | 独立核验动力学、整车扫掠、边界和制动尾段 | 候选轨迹、当前地图/路线版本 → 可用性及原因 | 修剪命令后继续沿用旧认证、触发搜索 |
| global_planner | 在稀疏高精度地图上生成几何路线 | 世界快照、起终点、预算 → 带版本路线/失败原因 | 局部实时控制、把求解失败写成障碍 |
| coordinator | 按独立周期调用组件并处理状态 | 快照、反馈、周期 → 已认证候选及事件 | 重新实现地图、搜索或求解数学 |
| fixtures / benchmark | 生成输入、运行离线闭环、保存证据 | 固定场景与配置 → 原始样本、统计和结果 | 混入算法决策、发布车辆控制 |

地图 epoch、路线 version 和轨迹来源贯穿接口。各模块仅保有自己的搜索或热启动状态；
地图及路线使用不可变快照，替换通过新对象完成。地图换版使旧认证失效；路线换版重新投影进度。
UNKNOWN、已知障碍、动力学不可行、求解失败和超时分别报告，不能互相冒充。

全局搜索在独立单 worker 进程中按周期推进，最多一个在途任务；局部循环不等待搜索。
快照与结果通过轻量序列化传递，接收方重建不可变对象。局部输出经过独立认证；候选无效时
采用重新认证的受限制动轨迹，不能用瞬时归零或冻结状态伪造停车。用户后续要求取消时间制动，
50 ms 改为软性能指标；晚到的有效轨迹继续执行，见 [软周期修订](2026-10-26-navigation-soft-budget-design.md)。

## 候选架构和指标

候选为多分辨率任意角全局规划、全局参考段和绕障候选、局部 MPCC 及独立轨迹检查。
wavestar 式二维适配和 MPCC 原型尚未实现。原有地图感知 MPPI 可作为对照，不代替候选结果。

暂定全局完整更新目标 1 Hz；逐步测试 100 m、500 m、1 km 地图。
暂定局部完整周期目标 20 Hz / 50 ms；包括地图更新、距离场、参考段、候选、求解及最终检查。
记录各阶段 P50/P95/P99/最大耗时、超时比例、内存、碰撞、约束违例及到达结果。
地图微基准不证明全局、MPCC、ROS 闭环或实车能力。

## 轮式配置基线

车体 1.182 × 0.818 m，前进/倒车最大 0.2 m/s；线加速度及制动减速度 0.5 m/s²；
角加速度 0.5 rad/s²，行进曲率上限 1.0 m⁻¹。验证采用部署控制器较严格的角速度限幅 0.1 rad/s。
这是配置值，实际响应及延迟需要独立标定。

1. 环境采集与地图处理开销：完成；5例×100计时，主结果最大26.59ms，仅地图处理；完整记录见任务根 REPORT.md。

三阶段已获用户授权连续推进。先执行离线算法验证，指标未达到时记录失败并针对瓶颈调整；
不以环境微基准或降低地图精度代替完整验证。首版全局原型允许采用保留 1 cm 边界的自适应
矩形空间分解与可见性捷径；这属于二维稀疏实现，不宣称是官方 wavestar 的完整复刻。

Windows 仅承担开发和静态检查；远端原生 Humble / Orin 算法证据与实车运动证据分别记录。


## 初轮历史结论（软周期修订前）

三阶段原型与适用验证已经实施，算法/编排代码独立审查完成；不代表指标全部通过。
全局规模与复杂通道1秒指标在已测样本通过，160条通道参考/20条封门无路均经独立门序和几何核验。
局部固定参考900稳态严格50ms失败（3.778%超时）；组合原档和用户授权高档.5m/s/.5rad/s也未稳定50ms。
原档已记录绕障/增障改道到达，多弯/紧通道未完成；高档实际峰约.42m/s/.50rad/s，未消除计算瓶颈。
用户要求收敛后停止长批次，后续地图限100m以内；本轮实际运动闭环均为25m以内布局、最长参考16.535m。
已归档1km/40km蛇形只属于全局几何计算，没有运行整条运动轨迹。最终结果与source版本见任务根REPORT.md。
原默认轮式.2/.1及生产代码不变；高档n20dt.1T2s属于独立离线配置。P3、ROS接口/实车仍NOT_RUN。
