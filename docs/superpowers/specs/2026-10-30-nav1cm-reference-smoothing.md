# NAV1CM全局参考整形设计

用户已确认上一轮分层方案并授权实现、测试、216部署和RViz验证，控制器保持启用。

全局搜索仍输出原始Route；nav1cm内部纯几何后处理产生供extract_reference/MPCC使用的Route，不增加独立规划器节点，不计算速度。保留raw_route供诊断。局部MPCC、整车/制动认证和控制器产品源码不改。

整形采用相切二次Bezier，裁切距离不超过邻段长度1/4和0.75m，采样间距至多0.05m；连续曲线及采样折线同时由递归凸包包围盒对膨胀障碍认证，触边拒绝，失败缩小裁切并回退原角。保持起终点、原地图/路线版本；所有数组不可变。预算25ms、顶点上限4096、有界细分/重试；耗尽时整个结果回退原Route，不能发布未证明的部分结果。

整形只在新全局路线被接受时计算；周期等价保留以raw_route比较。当前地图变化同时重验采样折线及曲线证明包围盒；失效则退休整条参考并触发已有全局重算，不在同版本下偷换几何。新路线版本重置进度并退休旧局部缓存；任务身份、执行参考摘要/配对、新鲜度及全部超时不变。

公共coordinator的reference_smoothing默认False，ROS新导航入口显式True；提供ROS smooth_global_reference参数便于诊断回退。既有global_route话题保留原始几何路线，新global_reference_topic默认为global_route_topic加_reference，发布实际供MPCC截取的同一整形Route；RViz灰色原始路线默认隐藏、青色全局参考、黄色局部路径。

216仅P4写入；记录基线并精确部署nav1cm/ROS planner文件，控制器PID保持，不重启/禁用控制器。部署需重启planner，保留原参数与目标来源记录；不自动创建额外导航目标。通过当前目标恢复/用户RViz选点验证非空平滑参考、实际局部reference一致性与正式PLAN_FOUND。若无可平滑角，使用真实地图快照上的独立离线几何验收，不伪造运行曲线。长期线不自动合并、不push、不删除。
