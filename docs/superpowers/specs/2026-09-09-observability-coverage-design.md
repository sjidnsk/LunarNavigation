# 可观测覆盖评估与全局目标候选设计

日期：2026-09-09。状态：设计完成，尚未实现、构建或部署。

依据：[面积排查记录](../../validation/2026-09-09-coverage-calculation-audit.md)、[洞穴提前检查](../../validation/2026-09-09-cave-preflight.md)、现有图探索与已知空间导航实现。本设计取代旧完整设计第 5.3 节的粗格排除规则，以及 `exhaustion.py` 的独立无阻挡上界；其余任务、控制及采样约束继续沿用。

## 1. 结论与适用范围

修正方向合理，但需要同时明确三个边界：

1. 可移动区域与可观测区域不同；不可进入的格也可能被观察，已观测障碍仍计面积。
2. 在线只能根据当前证据估计可观测范围，不能提前获得未知环境的精确分母。
3. 分母正确不会自动解决局部重复移动；扩大目标候选范围可以降低跨越已知区域的学习难度，但局部位姿动作也能逐段完成远距离转移，不能把它说成任务可完成的必要条件。

推荐采用一个统一的可观测覆盖评估器，并将扩大现有图目标候选范围作为独立验证的策略改进。评估器按细格移动连通性和独立遮挡证据求潜在观测集合；策略始终选择一个目标位姿 `(x, y, yaw)`，近处和远处的执行语义一致。沿用同一导航器和控制器，不建立第二个运动规划器。

覆盖修正不依赖候选扩展。初稿为远处目标引入了无指定朝向的动作，但这不是扩大目标范围所必需，现已撤回：不新增 `action_has_yaw` 或可选 yaw 契约，继续采用联合位置与朝向选择。后续验证先独立确认面积正确，再评价扩大候选范围的学习收益。

首版明确采用现有二维实体遮挡模型 `opaque_2d`，0.2 m 固定世界格。它不等同于真实三维传感器模型，不能根据一张可通行性图推导悬垂、透明物体或传感器高度影响。真实课题三输入如果只提供高程而没有可解释的二维遮挡证据，仍可运行，但在线排除会较少；不能把缺失信息伪造成精确可观测面积。

## 2. 方案比较

| 方向 | 收益 | 局限 | 结论 |
|---|---|---|---|
| 仅把排除分辨率改为 0.2 m | 修复部分薄墙漏通 | 未解决墙内外、视线和 BLOCKED 语义；仍可能漏排或误排 | 不采用为最终方案 |
| 全部使用仿真真值分母 | 仿真评分可固定 | 真实运行没有真值；旧 5 m 采样参考又会漏通道，不能直接作精确分母 | 保留独立审计用途 |
| 统一在线潜在可观测集合，参考值独立审计 | 训练与推理同一口径，覆盖与结束条件一致 | 需要观测到的遮挡证据，并控制可见性查询成本 | 采用 |

不通过降低 95% 目标、删除封闭洞室、把全部未知都扣除或强制换点制造完成结果。

## 3. 保留的任务约束

- 任务多边形由现有角点输入实现提供；只统计任务内面积，允许任务外绕行和从外部观察任务内。
- 8 个训练环境；平台前进、后退、行进中转弯和原地转向；速度上限 0.2 m/s；目标仿真倍率 10。
- 观测距离 10 m、水平视角 90°，继续通过配置调整。
- 局部窗口与导航器统一：64 m，0.2 m；地图范围可随探索增大。
- 任务不设时间上限；训练 256 个高层动作、自动验证 1024 个高层动作的预算仍属于采集器，预算结束为 truncated。
- 每 1800 s 保存；项目内沿用一个 resume、一个 best、有限经验快照及有界标量日志。
- 本轮不停止当前训练、不修改运行源码、不删除产物。实施与验证使用独立源码/构建环境，切换留到实现后的操作。

## 5. 地图契约：增加一个有明确来源的遮挡字段

### 5.1 字段

保留 `states`、`observed`、`costs`，在 `PolicyMapTile` 增加 `uint8[] occlusion`：

| K 值 | 含义 |
|---|---|
| 0 UNKNOWN | 没有可用的二维遮挡分类证据 |
| 1 CLEAR | 该有效观测格在 opaque_2d 模型中非遮挡 |
| 2 OPAQUE | 该格是 opaque_2d 模型中的实体遮挡，射线在首命中后停止 |

C 与 K 是独立信息。C==BLOCKED 不能自动生成 K==OPAQUE。K==OPAQUE 在本二维实体模型中也表示平台不能穿过该实体，但不回写或覆写导航的 C。

### 5.2 输入与持久化

在现有 GridMap 消息中允许一个可选层 `occlusion_2d`，与 elevation 使用相同尺寸、排列和变换：NaN 无证据，0 为 CLEAR，1 为 OPAQUE。`basic_layers` 仍只要求 elevation。探索模块不增加对课题三的订阅。

仿真只在本次 `observe()` 实际返回有效高程的位置输出该层；视野外和遮挡后的格保持 NaN。不能发布完整场景遮挡图。看到的首个障碍既是 O=1，也是 K=OPAQUE。

地图适配器处理可选层，并使用现有高程格的世界投影和有效观测范围对齐；不单独扩大观测范围。持久化到现有地图证据快照的 tile 中，不另建一套有独立坐标/epoch 的“探索地图”。最新有效 CLEAR/OPAQUE 可更新旧分类；无新证据不抹去历史分类；epoch 重置时一起清空。

缺少此层时 K 保持 UNKNOWN，不从坡度或膨胀结果猜测 K，也不阻止高程、导航或探索运行。实际课题三若以后提供占据、表面类别或明确的视线证据，由地图适配侧转换成该层；三维/高度相关遮挡采用后续独立模型，不在首版引入不透明高度阈值。

### 5.3 版本与增量

复用现有 epoch、raw_revision、fine_revision、minimum_map_stamp_ns 和 tile 增量协议，不新增另一套版本握手。

K-only 的有效变化也进入地图证据的 changed_cells/dirty_tiles，并生成包含该证据的新快照。细图派生对未变的 C 可复用内容，但导出版本必须能让消费者收到 K 的变化。现有 FineTraversabilityBuilder 会为新证据生成递增 fine_revision，现有 GetPolicyMap 可继续使用 since_revision。

`PolicyTile` 在 Python 中改为有名字的只读字段，避免依靠数组元组下标混用 C/O/K。协议长度、值域和坐标检查在适配/解码边界完成一次，不在候选循环逐格重复增加检查。

## 6. 统一面积定义

令 T 为固定世界格中心落在任务多边形内的集合，a=r²，r=0.2 m；O 为截至本次决策已有有效证据的任务内观测集合。

Q 是在当前证据下潜在可到达的观测位置集合。V_plus(q) 遵守已知遮挡，对未知遮挡保持乐观。首版以细格中心作为统计用观测位置，并将所有潜在朝向的可见集合求并；这是统计网格估计，不是连续 SE(2) 可达性证明。

```
E = O ∪ (T ∩ union V_plus(q), q ∈ Q)
X = T \ E
R = E \ O
A_T = |T|a
A_O = |O|a
A_E = |E|a
A_X = |X|a
A_R = |R|a
C_task = A_O / A_T
C_eff_est = A_O / A_E
```

保证 E 包含 O，已经观测的障碍不会因不可通行或排除判断而从分子消失。排除增加本身没有覆盖奖励。地图更新可撤回排除，因此 C_eff_est 允许下降。

A_R=0 时，同时表示估计耗尽与 C_eff_est=100%（合法非空任务）；不再维护一套能与此相矛盾的“还有墙后潜在面积”判据。正常结束仍以 C_eff_est≥0.95 为准，不要求先达到耗尽。

## 7. 可计算的算法

### 7.1 计算范围与虚拟外部

使用当前全部证据范围、任务范围和当前位置的联合包围范围，向外扩展传感量程及一圈未知格。该边框只是计算边界，不是障碍。

未分配格初始化为 UNKNOWN。边框外用一个虚拟外部连通关系表达：只有连接计算边框的分量可以通过它互通；不能把所有未分配 tile 无条件连到外部，封闭墙内的存储空洞必须仍然是内部未知。

当前地图外没有已知障碍证据，因此通过虚拟外部连接边界分量是乐观的绕行表达。任务边界不参与连通性判断。

### 7.2 潜在移动集合 Q

移动屏障为 `C==BLOCKED`，以及本二维实体模型中 `K==OPAQUE` 的已观测实体格。其余，包括 UNKNOWN，作为潜在可移动格。

从当前平台所在格及同一快照已有的 start connectors 播种，计算与平台连通的潜在移动分量。复用导航提供的起点连接，不给平台挖 FREE 区，不对候选调用第二个规划器。此集合仅用于面积估计，不能给导航器作可达性证书。

使用四邻接做分量标记。它与当前八邻接但禁止穿角的移动图具有相同分量连通关系；距离仍由原导航/观察图计算。

若平台分量连通计算边框，则将各边框分量经虚拟外部合并；若平台被闭合屏障包围，边框外的分量不能因为“开放”就自动加入 Q。

### 7.3 两次廉价筛选，减少射线查询

1. 未观测且属于 Q 的任务格直接保留为潜在观测区域。这是未知空间的乐观估计，避免只保留已经走到的地方。
2. 在 `K != OPAQUE` 的光学连通图上，从 Q 播种得到 L，同样正确处理虚拟外部。光学不连通的未观测区域不可能被看见。
3. 对 Q 做欧氏距离变换；距离超过传感量程的格不能从 Q 观测到。

剩余需要查视线的集合为：

`D = (T \ O \ Q) ∩ L ∩ {distance_to_Q <= range}`。

光学连通和距离只用来排除不可能情况，不能直接把 L 或距离膨胀当作可见区域。封闭洞穴通常在光学连通筛选阶段就能移除大块外侧岩体；可通行性受限但不遮挡的坡面仍进入后续视线检查。

### 7.4 视线查询与首命中

对 D 中每个格，检查量程内是否存在 Q 中的位置与它有直线视线。可以从目标反向查询 Q；细格中心间的无阻挡直线关系对称。先测试近处来源，发现一个可见来源即结束，失败则完整检查余下来源，不能只采几个角度就判定不可观测。

使用统一的 supercover DDA 栅格规则：检查穿过的格，穿角时检查两侧，首个实体格本身可见，之后不可见。局部候选使用实际连续位姿和实际 90° 视角；全局潜在面积求所有潜在朝向的并集。允许全朝向是在线潜在估计，不能据此断言每个位置都能实际完成整圈转向。

```
def compute_potential(view, task, seed, sensor):
    Q = connected_to_seed(~movement_barrier(view), seed, virtual_exterior=True)
    L = optical_components_touching(Q, view.occlusion, virtual_exterior=True)
    direct = task & Q
    D = task & ~view.observed & ~Q & L & within_range_of(Q, sensor.range_m)
    visible = any_visible_from_region(D, Q, view.occlusion, sensor.range_m)
    return task & (view.observed | direct | visible)
```

此处是离散估计。实际连续移动偶尔得到旧 E 之外的新观测时，O 的有效证据优先：重新并入 E，并保留一个累计面积诊断值供参考审计，不拒绝观测、不阻断训练。

### 7.5 缓存和重算

第一版使用 NumPy/SciPy 完整细格分量/距离计算，并复用工作数组；避免同时建立 tile 分量图、层次图及多套拓扑状态。底层仍从已有稀疏 tile 读取，不持有第二份高程或导航地图。

C 或 K 的内容、任务、平台所在分量、传感模型变化时，重算潜在集合。只有 O 增加时，更新账本和 R；同一连通分量内的平台移动不改变 Q。K 撤回或 C 放通时同样重算，不能使用只增不减的排除缓存。

原生可见性内核用小型 C++ Python 扩展 `lunar_observability_native` 执行批量 DDA，释放 GIL，通过 Python 缓冲区协议接收连续数组和只读掩码，不依赖 NumPy 的 C ABI；不增加外部服务或仿真平台依赖。保留简单的 Python 标量 DDA 作为测试参考，实现与仿真模型逐案例核对。

## 8. 决策边界与结束条件

沿途每次有效地图更新仍立即积累 O 和物理路程。覆盖分母与结束判定在现有的“导航目标结束、控制停止、最后地图处理完成”的高层决策边界统一刷新。

删除导航进行中用旧排除值提前取消目标的路径，避免在传感/控制周期反复全图计算，也避免分母撤回前用过期统计结束任务。到达 95% 后可能多走当前目标的剩余距离，仍按实计入；不新增控制状态机。

环境和实际推理使用同一个 CoverageEvaluator。输出 `CoverageSnapshot` 带现有 epoch/revision，以及 A_T/A_O/A_E/A_X/A_R、C_task/C_eff_est、exhausted 和 metric_version。

- 达标：C_eff_est≥目标且没有碰撞，reason 保留 COVERAGE_REACHED，basis 明确为 online_estimate。
- 耗尽：A_R=0，作为同一快照的统计依据；非空任务也已满足覆盖目标。
- 零新增、局部无正收益、位于地图外缘：均不自动结束任务。
- 采样预算：Collector 设置 truncated；不产生成功奖励，保留价值自举。
- 定位、接口、导航异常：沿用现有处理，与覆盖算法解耦；不伪装成完成或耗尽。

## 9. 保持目标位姿语义，扩展候选范围

### 9.1 共用遮挡与面积语义

`ObservationGraph._directional` 停止使用 C==BLOCKED 遮挡射线，改为调用 VisibilityQuery；候选增益始终是 `T \ O` 中本次视角可见的面积。36 个方向可继续用作网络的压缩描述，但不能把稀疏方向采样用于全局排除证明。

任务区域 token 分别表达任务面积、已观测面积与估计剩余可观测面积；被排除的未知不再作为区域探索收益。原始未观测总面积仍由 A_T-A_O 提供，不混淆。

### 9.2 统一动作集合

动作仍是从冻结图快照中选择一个 `(节点, 朝向)`，解码为 `Pose(x, y, yaw)`。每个可选节点使用现有 12 个朝向；不区分“观测动作”和“无朝向转移动作”两种执行类型。

近处继续保留细图节点，远处使用现有区域分量的已知 FREE 代表点。图中与平台连通的 type=0 细节点及 type=1 区域代表点均可生成目标，细节点即使图距离超过 10 m 也保留，避免需要绕行的近点丢失。10 m 只控制局部图细节，不再作为目标图距离的硬上限。直接复用现有节点及其代表点，不构造额外的“脱困候选器”。纯任务 token、临时非 FREE 起点和 UNKNOWN 位置都不是目标。动作距离必须是到实际代表点的图距离，不能使用整个区域内任意节点的最小距离代替。

所有目标继续发送 `NavigateToPose(has_target_yaw=true)`，导航到达目标位置后对齐所选朝向。到远处目标后同样完成一次观测；转移过程中获得的观测与实际运动一并计入该动作。

候选构造负责提供目标位姿，Actor 负责选择，导航器负责实际规划与跟踪。候选只复用已有的 FREE 和图连通规则，不为每个候选再跑一次规划认证。

远处候选始终可选，不因为局部收益为零才临时开放，也不使用连续 N 次无收益、黑名单、冷却或强制接管。Actor 从一张变长动作表中统一选择，保持同一个 SAC 策略。此改进减少一次长转移需要策略反复决策的次数，不能据此保证网络已学会全局探索。

### 9.3 特征和执行

`GraphSnapshot.action_poses` 继续为 `[N,3]`，`goal(index)` 继续返回现有 `Pose`；不增加 `NavigationGoal`、`action_has_yaw` 或动作类型字段。

动作特征保持 12 维，节点 158 维，边 2 维。每个远处代表点也计算自身的方向摘要；具体动作使用所选朝向的实际视野收益，与近处候选同义，不把全朝向并集伪装成单次 90° 观测收益。预测收益只用于决策特征，不当作已经获得的奖励。

局部栅格增加 occlusion_known、opaque 两个通道，从 8 通道变为 10 通道。保留 16 维统计向量及 2 维实际执行量；previous_action 继续记录所选目标的归一化相对位移及目标 yaw，实际结束位姿和运动量仍使用现有状态与执行字段。

网络预处理对图中的距离量采用固定 `asinh(distance/10 m)`，有符号相对位移使用相应 asinh 归一化；地图几何和导航目标仍使用真实米坐标。模型/观测契约升级为 v3，graph_schema 保持 [158,12,2]，coverage.metric_version 改为 observability_grid_v2。升级的依据是遮挡输入、特征预处理和覆盖结束口径的变化，不是目标位姿动作改成了另一种类型。

一次远处目标导航仍对应一条高层转移，完整累计沿途面积、长度和旋转。保持现有每高层决策的折扣 0.999 及奖励权重，明确它不是按秒折扣；本次不再同时改成按时间/路程折扣，避免混入另一套学习目标。

远处代表点也展开 12 个朝向，因此需要测量大图候选数、Actor 耗时及有界回放容量。继续使用现有区域压缩减少远处位置节点，不通过额外候选审批或强制朝向规则解决容量问题。

## 10. 训练、推理与参考审计

训练和实际推理都使用在线 E_est 作为策略统计输入和任务达标口径。参考集合不输入 Actor、Critic、候选生成或在线地图。

奖励保持物理增量：

`r = ΔA_O / 78.539816 - 0.01 ΔL / 10 - 0.001 Δrotation/(2π) + 5 success - 原有失败项`。

只有实际新增 O 有面积奖励；扣除岩体内部没有面积奖励。远处目标的长路程和沿途观测均计入这一次转移，不奖励“到了一个新区域”标签本身。

`reference.py` 保持独立仿真审计，报告 C_ref、采样分辨率及实际观测落在参考集合外的面积。现有 5 m 位置采样不是精确真值，尤其可能漏过窄通道；小型几何用穷举/更细采样核对，大场景参考结果明确标为采样估计。不能用稀疏参考分母证明实际 95% 完成。

验证记录分别列出 estimated_target_reached 与参考审计结果。学习策略在固定地图上的成功率是学习效果评价；不要求新网络尚未训练就跑完全部洞穴，才允许开始训练。

## 11. 性能与存储可行性

本机在持续训练运行时，对合成薄墙网格测得单次四邻接连通标记：

| 范围 | 细格数 | 单次标记 | 输入与标签数组 |
|---|---:|---:|---:|
| 50 m | 62,500 | 0.82 ms | 0.30 MiB |
| 100 m | 250,000 | 1.82 ms | 1.19 MiB |
| 300 m | 2,250,000 | 16.17 ms | 10.73 MiB |
| 1 km | 25,000,000 | 152.98 ms | 119.21 MiB |

这只证明原生细格连通计算可行，不是完整覆盖算法、真实洞穴、8 环境或 1 km 闭环性能证据。加入任务外区域会扩大数组，可见性查询可能成为主要成本。

实际控制成本的方法：只在决策边界刷新；C/K/分量未变化则复用 E；复用分量标签缓冲；先用 Q/L/距离排除大部分视线查询；DDA 在原生扩展中批量早停。不先增加复杂的多级分量缓存框架。

每格 E/X/R 不分别存三份稠密图：保留潜在 E 位图与 O 账本，X/R 由集合差和计数得到。工作数组按一个完整计算依次复用，完成后可释放。参考真值计算独立、按需运行，不为每个训练进程长期驻留完整参考图。

继续使用当前总资源预算，不预分配满 1 km 地图，不新增经验或模型副本。只记录面积、结束原因、覆盖计算耗时及局部/全局动作次数等少量标量到现有 metrics 文件。

## 13. 必要验证，不增加运行准入流程

工程正确性验证包括：薄墙闭合、墙内/外种子、窄洞口、部分观测格、任务外绕行、可通行性受限但不遮挡、首命中计面积、K 撤回、K 缺失继续运行、K-only 增量、采样截断，以及远处目标仍执行完整位姿与终点朝向。

算法小图与独立穷举可见性对照；真实闭环使用现有导航/控制，在小洞穴验证观测、面积和结束的连贯性，并验证 8 域并行不串扰。大图测量实际时间和峰值内存，结果如实记录。已有安全/运动能力约束不降低，也不在覆盖模块复制这些验证。

不增加最小观测百分比、最少成功次数、必须全部基准达标、逐候选规划审批或未知遮挡拒绝启动的门槛。网络的 95% 成功率作为训练目标持续评估，不作为启动训练的先决条件。

此前独立评估的取消请求超时仍是已记录的生命周期问题；不能由本设计推断已经解决。实施验证需记录正常结束和显式取消的各自结果，若取消仍失败，在现有导航关闭路径内单独定位，不归入面积算法。

## 14. 实施顺序与训练迁移

1. 地图 O/C/K 契约与实际局部遮挡观测链。
2. 共用可见性内核及统一 CoverageEvaluator，删除旧排除/耗尽算法。
3. ObservationBuilder 与图收益统一接入；面积算法先独立验证，候选范围扩展单独验证，后者不是前者通过的条件。
4. 环境、推理、模型 schema、日志与采样边界一起接入。
5. 小图对照、Jazzy 闭环、8 环境与尺寸性能验证，更新操作文档。
6. 完整方案实施后，建议在后续切换操作中使用新模型/新回放训练：现有样本没有新增遮挡输入，覆盖终止口径及特征预处理也不同，不能把旧 resume 直接当作严格接续。仅扩大候选范围不等于必须重建网络或清空经验，需另行核对冻结历史候选与学习目标；兼容权重初始化也不同于完整恢复。本方案不编写复杂的旧回放迁移器。按现有检查点配置保留与替换产物，切换前不清理运行中的数据。

当前训练继续运行；此设计不会自动触发停止、清除经验、重启或部署。
