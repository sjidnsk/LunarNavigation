# 探索覆盖面积与可探索面积的简化定义

日期：2026-09-08

状态：指标定义已获用户确认；本文为设计基线，新增统计尚未实现。

核对源码基线：`integration/pure-planner-orin`，`df469d16fcc46d633ac772e30b368967771e1c30`。

## 1. 任务与计算范围

任务输入为探索区域多边形，典型环境为月表、熔岩洞。目标是使探索覆盖率达到指定值，
不以固定时间预算限制探索。传感器量程和视野可配置，观测需要考虑遮挡。

本定义使用当前二维探索地图计算水平投影的栅格面积，不计算洞壁、洞顶的三维表面积。
已知障碍格计入已探索面积；障碍背后和封闭区域内的未知格不能直接算作已探索。

保留现有架构：导航器生产探索地图，探索器统计覆盖并选择目标，导航器规划执行路径，
控制器跟踪路径。本文只确定覆盖指标、排除估计和后续奖励的面积口径。

## 3. 栅格与面积定义

设地图分辨率为 `r`，单格面积为 `a = r²`。栅格中心位于任务多边形内部或边界上时，
该格属于任务。面积统计统一使用任务栅格，精确多边形面积仅作辅助报告。

以下数量均只统计任务范围内的格子：

- `N_F`：已知可通行／候选格数量。
- `N_B`：已知障碍／不可通行格数量。
- `N_U`：未知格数量，包括地图内 UNKNOWN 和地图外 OutsideMap。
- `N_X`：未知格中按第 4 节规则估计可排除的数量；始终满足 `0 ≤ N_X ≤ N_U`。

| 指标 | 含义 | 计算式 |
| --- | --- | --- |
| 任务面积 `A_T` | 任务的全部栅格面积 | `(N_F + N_B + N_U) × a` |
| 已探索覆盖面积 `A_K` | 地图中已获得状态的面积，包括已知障碍 | `(N_F + N_B) × a` |
| 未探索面积 `A_U` | 尚未获得地图状态的面积 | `N_U × a` |
| 估计排除面积 `A_X` | 按简化模型可暂时排除的未知面积 | `N_X × a` |
| 估计可探索覆盖面积 `A_E` | 预计可以完成观测的总面积，包含已探索部分 | `A_T - A_X` |
| 估计剩余可探索面积 `A_R` | 预计仍需完成观测的面积 | `A_E - A_K = A_U - A_X` |

必须满足：

```text
A_T = A_K + A_U
A_E = A_K + A_R
0 ≤ A_X ≤ A_U
0 ≤ A_K ≤ A_E ≤ A_T
```

覆盖率同时保留两种口径：

```text
C_task      = A_K / A_T
C_effective = A_K / A_E
```

`C_task` 表示任务原始覆盖率；`C_effective` 表示按估计可探索区域计算的覆盖率。
有效分母下有 `0 ≤ C_task ≤ C_effective ≤ 1`。
空任务、非正面积或其他无效输入不能据此宣告完成；分母为零时相应指标无效。

## 4. 封闭未知区域的排除估计

### 4.1 简化假设

首版只识别被已知障碍完整包围、与平台所在区域不连通的未知区域。
为便于计算，将参与封闭判断的 BLOCKED 格视为二维不透明屏障。

这是工程近似：不可通行坡面、低矮障碍可能仍允许传感器看到其后方。
因此 `A_X` 必须称为“估计排除面积”，不能称为已经证明的不可观测面积。
若场景不能接受这一近似，应保留这些未知格，即不进行该排除；更精确的处理需要遮挡几何证据。

该方法不枚举全部可达观测位姿，也不求真实可观测区域的精确并集。
它可能保留其他实际无法探索的区域，也可能因粗栅格和不透明假设而错误排除部分区域。

### 4.2 计算步骤

输入为完整的当前探索地图、任务栅格和同一坐标系下的平台有效位置。

1. 在当前地图的完整数组范围内，将 FREE 和 UNKNOWN 作为潜在可连通格，将 BLOCKED 作为屏障。
2. 对潜在可连通格执行八邻域 BFS，标记连通分量，并记录分量是否接触地图数组边缘。
3. 用平台所在的有效 FREE 格确定平台分量。若没有有效种子，本次取 `A_X = 0`，
   并标记排除估计不可用，不能使用调整后的指标触发任务完成。
4. 筛选不属于平台分量、且不接触地图数组边缘的分量。
5. 只统计这些分量中位于任务多边形内的 UNKNOWN 格，得到 `N_X`。
6. 按第 3 节公式计算面积和覆盖率。

UNKNOWN 参加连通计算，只表示“可能存在尚未发现的通道”，不构成可执行路径。
八邻域使对角处尚有间隙的区域继续保留，减少将细小通道误判为完全封闭的情况。
导航器仍按自身的地形、平台尺寸和运动约束判断可达性。

连通计算先使用完整地图，最后才与任务范围求交。任务多边形是本指标的计数边界，
不能在连通判断时被当成障碍墙。是否允许平台驶出任务区绕行由任务执行规则决定，
本指标不授予该权限。

以下区域不能因为本规则被扣除：

- 任务内的 OutsideMap 格；
- 接触地图数组边缘的未知分量；
- 经未知通道与平台分量相连的区域；
- 已经判定为 FREE 或 BLOCKED 的格子，包括封闭分量内先前已知的格子。

排除结果仅保存为派生掩码，不改写原始 UNKNOWN 状态。地图、任务或平台分量变化后重新计算；
发现通道或更正障碍状态后应恢复相应未知面积，调整后的覆盖率允许随估计修正而下降。

地图连通标记的时间和空间复杂度均为 `O(N_map)`；加上任务范围统计，
总时间为 `O(N_map + N_task)`。首版采用完整重算，后续再根据实测开销决定是否增量更新。

### 4.3 与传感器模型的关系

量程、视野和遮挡通过实际地图观测更新影响哪些格子变为已知。
覆盖统计不把整个传感器扇形直接记为已探索，也不把候选目标的信息增益预测记为实际覆盖。
封闭区域排除只使用上述二维近似，不等同于完整的传感器可观测性计算。

## 5. 数值示例

取 `r = 1 m`，任务包含 10000 格，其中 FREE 为 6000 格，BLOCKED 为 2000 格，
UNKNOWN 与 OutsideMap 合计 2000 格。假设其中 1000 个 UNKNOWN 格符合排除规则。

| 指标 | 结果 |
| --- | --- |
| 任务面积 `A_T` | 10000 m² |
| 已探索覆盖面积 `A_K` | 8000 m² |
| 未探索面积 `A_U` | 2000 m² |
| 估计排除面积 `A_X` | 1000 m² |
| 估计可探索覆盖面积 `A_E` | 9000 m² |
| 估计剩余可探索面积 `A_R` | 1000 m² |
| 原始覆盖率 `C_task` | 80% |
| 按估计可探索区域计算的覆盖率 `C_effective` | 88.89% |

已知障碍的 2000 m² 始终计入已探索面积；被扣除的未知格没有因此变成已探索格。

## 6. 与现有统计的对应关系

保留现有字段语义：

```text
A_T = task_raster_area_m2
A_K = known_free_area_m2 + known_occupied_area_m2
A_U = unknown_area_m2 + outside_map_area_m2
C_task = coverage_ratio
```

注意：现有 `unknown_area_m2` 只包含地图内未知面积，不能单独作为本文的 `A_U`。

后续建议新增以下派生字段；这些名称目前是设计建议，并非已经存在的接口：

| 建议字段 | 含义 |
| --- | --- |
| `excluded_unknown_area_m2` | `A_X` |
| `explorable_area_est_m2` | `A_E` |
| `remaining_explorable_area_est_m2` | `A_R` |
| `effective_coverage_ratio_est` | `C_effective` |

原始 `CalculateCoverage(TaskRaster)` 继续负责已有计数。新增排除估计需要完整地图和平台位置，
不能仅凭裁剪后的任务栅格完成。输出还需能够区分有效估计、排除未启用和输入无效。

## 7. 目标判定与强化学习奖励的约束

目标阈值使用配置值。后续按 `C_effective` 判断目标时，结果必须明确标注其估计分母，
并同时报告 `C_task` 和 `A_X`。达到阈值表示在当前估计下达标，不代表真实任务区域同样比例已被观测。

当前 [增量探索节点](../../../ros2_ws/src/lunar_pure_exploration_ros/src/incremental_exploration_node.cpp)
仍按原始 `coverage_ratio` 比较 `coverage_target`；无前沿时也可能以
`COMPLETED_NO_REACHABLE_FRONTIER` 结束。本次只记录设计，不改变这些运行逻辑。
后续结果统计必须区分“覆盖目标达到”和“当前无可执行探索目标”，不能仅看 `COMPLETED`。

平台在已知通道内移动时，短期新增覆盖为零是正常情况，不能单独作为探索结束条件。

强化学习的覆盖奖励来自本任务中首次获得地图状态的面积：

```text
reward_area(t) = 本步首次观测为 FREE 或 BLOCKED 的任务格数量 × r²
```

同一物理栅格重复观测不重复奖励；排除掩码变化、分母缩小、预测信息增益都不直接产生该奖励。
后续训练实现需按任务保存首次已知记录，在任务开始时初始化已有观测；地图滑动或重建时不能
仅凭数组下标识别同一格。原始覆盖统计仍保留当前地图口径。

## 8. 后续实现的验收场景

下表为待实现时的验收要求，不是已经通过的实现测试。

| 场景 | 预期结果 |
| --- | --- |
| 已知 FREE 与 BLOCKED 混合 | 两者均计入 `A_K`。 |
| 完整障碍环内有未知格，平台在环外 | 符合二维假设时，只扣除环内未知格。 |
| 障碍环留有 UNKNOWN 通道 | 保留环内区域，避免提前判定封闭。 |
| 只存在对角潜在通道 | 八邻域仍视为可能连通。 |
| 不连通分量接触地图边缘 | 不扣除，避免将地图截断当成封闭障碍。 |
| 任务边界截断一个通道 | 依据完整地图连通性判断，不能因任务裁剪而封闭。 |
| 任务多边形超出当前地图 | OutsideMap 保持未知并计入分母。 |
| 封闭分量内有先前已知格 | 已知格保持计入 `A_K`，只扣除未知部分。 |
| 平台有效位置缺失或所在格非 FREE | 排除估计不可用，不触发调整后覆盖率完成。 |
| 后续地图恢复了连通通道 | 撤回相应排除，恢复剩余面积。 |
| 空任务或零分母 | 指标无效，不能宣告 100% 完成。 |
| 仅排除面积增大，没有新增观测 | 调整后比例可变化，覆盖奖励为零。 |
