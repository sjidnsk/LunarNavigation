# MPPI 路径跟随器

用户确认名称及职责：`mppi_path_follower`。现有 `mppi` 为地图感知版本，默认 `pure_pursuit` 保留。

输入为原 `PathReference`、同源里程计/TF及已发布命令历史。保留32样本、40×0.05秒预测、一次加权更新、现有路径/航向/平滑代价及速度、角速度、加减速、曲率、横向加速度约束。加权控制重新预测运动约束。公开到达标准及实测停稳不变。

该后端不请求地图，不计算地形代价，不进行逐候选地图认证或多延迟情景完整刹停认证。路径规划、地图更新与路径失效归上游。上游路径有效不等于车辆实际运动不会切角，不能将该后端声明为带障碍安全保证的控制器。

复用MPPI状态机与接口，通过 `requires_map` 和代价函数拆分职责；地图感知版本保持原行为。路径跟随器批量预计算时域内独立的限幅，保留逐步递推次序；与原投影逐元素相同。

启用使用原ROS节点参数 `controller_backend:=mppi_path_follower input_mode:=incremental_reference`。实际名义响应须按平台标定，零指令队列运动学仿真配置 `mppi_nominal_response_time_s:=0.0`；40ms仅统计，不直接停车。

初版验证（历史结果）：329项控制器/节点测试通过；同一16个静态场景下，地图感知MPPI16/16完成、0碰撞；路径跟随器14/16完成、2场贴墙碰撞。两个地图变化场景在上游路径失效通知后均停车，三个原生导航目标均到达、0碰撞。性能与质量证据见 `/mnt/data/WS/lunar-navigation/analysis-artifacts/mppi-tracking-cost-20261018/REPORT.md`。不修改运行中的200场封存评测，不切换默认后端，不据少量样例证明总体成功率或实车可用。


## 跟踪精度修正

用户批准按连续路径全过程误差→对称采样→速度/纠偏协调顺序修改。当前采用连续线段投影、1cm横向与0.05rad航向代价尺度、角速度镜像样本、预测时域匹配接近速度和尖锐顶点停稳转向。保留外部路径/session/到达契约；公开终点0.1m精度与毫米级横向误差是不同指标。

最终346项测试通过，16静态场景16/16完成0碰撞、12次种子/延迟组合12/12完成0碰撞、原生三个目标3/3完成0碰撞。首版两场贴墙失败最大横向偏差由碰撞前约10mm降至0.14mm和1.03mm。完整证据与被拒绝变体在 `/mnt/data/WS/lunar-navigation/analysis-artifacts/mppi-tracking-error-20261018/REPORT.md`。默认后端和200场封存版本未改，实车与新跟随器完整200场仍未验证。
