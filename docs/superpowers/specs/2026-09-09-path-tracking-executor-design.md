# 轮式路径跟踪执行器重构

用户已确认：前进和后退均可转弯，可原地旋转，不能横移；平移上限0.2 m/s。
本次直接执行重构授权，不重复请求设计批准。工作树沿用已隔离的feat/drl-exploration-training。

## 方案选择

采用独立、有状态的几何路径执行器，配合受限的前视跟踪和停车对齐。保留纯路径和legacy定时轨迹入口，
训练改用已有PathReference作为带身份的权威输入，并增加TrackingStatus反馈。没有引入MPC依赖，
没有在原track_path函数中堆叠状态补丁，也没有把规划/重规划放进控制器。

## 模块与接口

- path_geometry.py：只负责不可变折线、累计弧长、线段投影、前视插值和转角识别。
- execution.py：PathExecutor，持有参考身份、段进度、方向、执行阶段和无进展状态；无ROS依赖。
- tracking.py：保留legacy轨迹计算和通用值类型；旧track_path成为调用新执行器的兼容入口，节点不使用该无状态入口。
- node.py / frame.py：消息、速度状态、QoS和计时适配；任何缺失/陈旧状态立即输出零指令。
- TrackingStatus.msg：session_id、segment_revision、阶段、进度、横向误差、朝向误差、失败原因。
- 导航节点只接收匹配当前session/revision的FAILED反馈，停稳后通过原规划状态机触发重规划；旧消息不改变当前目标。
- 训练RosEnv改用incremental_reference；watchdog基于实际执行进展，而不是完整目标固定120秒。

## 执行约束

阶段为WAITING、BRAKING、ALIGNING、TRACKING、FINAL_ALIGN、COMPLETED、FAILED。
新参考从实际位姿投影。相同参考重复发送不清进度；不接受同一session较旧revision。
方向在每份参考内锁定，后退使用行进坐标系计算曲率；大偏航可原地旋转。
平移与旋转允许同时存在；超过可行曲率的尖角在点附近停稳并转向，不跨尖角取前视点。
每段终点朝向均须执行，非最终段用0.04 m位置容差；最终段用0.2 m。
启用反馈时导航最终成功也须收到匹配的COMPLETED，已完成的非最终局部目标不能重复作为新进展。
终态只在实际线速度和角速度均已停止时成立，位置接近目标不能提前吞掉剩余路径。
正常跟踪联合求解平移和角速度的可行区间，满足速度、曲率、横向加速度、加减速度和停车距离约束。
制动/失效时输出零目标速度，由底层执行已配置的物理制动；只有实测速度低于0.01 m/s和0.03 rad/s才确认停稳。
路径偏离基于线段，不使用顶点距离；控制失败反馈不再依赖导航的更大偏离阈值。
没有传感器输入时不能通过真值保护控制器。避障仍由导航地图和参考负责；控制器不发明未验证的绕障路径。
全地图动态碰撞安全的形式证明不在本次范围，必须以代表性障碍、反向、转角与更新回归记录实际边界。

## 验收

长线段中点不误停；E7大偏航起步先对齐且沿安全参考进展；正反向弯道；尖角停车；
原地/最终转向制动；速度/曲率/加速度；路径更新、清空与迟到revision；陈旧位姿停止；
跟踪失败匹配身份触发重规划；前进和旋转均可刷新无进展检测，正常长目标不因120秒截断。
既有ROS三项回归全部通过，补充E7实际闭环；Jazzy/Humble分开构建和测试。
训练旧存档原样保留，不自动重启训练或清除旧经验；不合并、不推送、不接入车辆。
